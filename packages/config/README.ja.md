# Gyomu Config

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuプロジェクトにおける集中管理型の設定基盤です。グローバル、ユーザー、およびスコープごとの各ソースを横断してアプリケーション設定を管理、統合、解決するための堅牢な仕組みを提供します。階層的な解決手法を実装することで、アプリケーション全体で一貫した設定管理を実現します。また、関数型プログラミングの原則とEffect Schemaによるバリデーションを活用し、生の入力を信頼性の高い型安全なデータ構造へと変換します。このアプローチにより、すべての利用者が検証済みの設定を受け取ることが保証され、プロジェクト全体を通じて型安全性と運用の整合性が維持されます。

## アーキテクチャ

本アーキテクチャは、アプリケーション設定管理の主要な入り口となる中核的な Configuration Resolution Service を中心に構成されています。このサービスは、グローバル、ユーザー、およびスコープ化された各ソースからデータを収集することで取得プロセスを統括し、厳格な優先順位とマージロジックを適用して、一貫性のある型安全なアプリケーション状態を生成します。このライフサイクル全体を通じて、サービスは検証を実行し、結果をアプリケーションに渡す前に設定の整合性を保証します。

堅牢な運用をサポートするため、本パッケージは専用のエラー管理層を備えています。このコンポーネントは、解決プロセス中に発生した障害を捕捉・分類し、コンテキストを提供します。エラーを特定のライフサイクルフェーズにマッピングしてメタデータを付与することで、利用側は設定ルックアップの耐障害性や再試行可能性を評価でき、解決時に中断が発生した場合でも信頼性の高い状態管理を実現します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/config
```

## 依存関係

本パッケージはNode.jsを必要とし、ESM環境向けに設計されています。Effect 4.xと完全な互換性を持ち、Effectをランタイム、スキーマ、およびコンテキストの基盤として活用します。機能は@gyomu/schemaおよび@gyomu/infraライブラリに基づいて構築されており、共有の型定義とインフラ層のI/O操作を処理します。本パッケージのアーキテクチャをサポートするため、これらの依存関係がプロジェクト環境に含まれていることを確認してください。

## 開発

このパッケージは、Gyomuプロジェクトにおける設定管理の信頼性を担保する中央集権的な基盤として設計されています。グローバルおよびユーザーといった複数のスコープから提供される設定を階層的に解決し、単一の整合性のあるアプリケーション状態を構築することが目的です。貢献者は、設定ソースへの直接アクセスを厳禁とし、すべての設定取得を`ConfigResolver`経由で行うことで、アクセス経路の完全な制御と抽象化を維持してください。

アーキテクチャの根幹は、Effect Schemaによる「検証を通じた型安全性」と「宣言的な解決プロセス」の両立にあります。設定は取得の過程で必ず検証されるため、不正な設定値がアプリケーション内部へ流出することはありません。拡張を行う際は、既存のAPI設計を維持しつつ、新たな設定種別やスコープをプラグイン可能な形式で追加できるよう設計してください。また、設定解決時の障害発生時は、単なる例外ではなく、診断に必要なメタデータを含む構造化されたエラーとして表現することで、システムの堅牢性とデバッグの容易性を向上させることが求められます。

## Public API

- 設定解決サービス - 特定の解決基準に基づいてアプリケーション設定を照会および取得するためのプライマリインターフェースを提供します。
- 階層型マージ - 異なるスコープ間で設定データの集約を自動化し、グローバル、ユーザー、および機能コンテキスト間での一貫した優先順位を確保します。
- フォールトトレラントな解決 - 豊富なエラーコンテキストとライフサイクルトレーシングを提供し、解決の失敗に対するハンドリングやリトライの可否判断を可能にします。
