# Gyomu Config

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuプロジェクトにおける集中管理型の設定管理システムです。グローバルおよびユーザーごとのスコープにわたる設定の取得、階層的なマージ、検証を行うための堅牢なインフラストラクチャを提供します。

Effect Schemaによる厳密な検証を統合することで、すべての設定データが型安全であり、アプリケーション全体で一貫していることを保証します。このアプローチにより、複雑な実行環境に応じた設定を管理するための統一された基盤が構築され、開発者は信頼性の高い検証済み設定へアクセスしつつ、アーキテクチャの整合性を維持できます。

## アーキテクチャ

本パッケージのアーキテクチャは、設定取得のライフサイクルを管理する堅牢な解決（Resolution）サービスを中心に構成されています。このサービスは、グローバル、ユーザー、スコープに基づく各ソースを階層的にマージし、優先順位ルールを適用して、整合性のある型安全な設定オブジェクトを生成します。このロジックを集約することで、すべての設定が定義されたスキーマに準拠することを保証し、アプリケーションが検証済みデータへアクセスするための統一されたAPIを提供します。

診断の明確さに関する責任は、専用のエラー管理コンポーネントに分離されています。このサブシステムは、ライフサイクルのフェーズごとに設定エラーを分類し、重要なメタデータを取得することで、正確なエラー報告と適切な復旧戦略を可能にします。解決ロジックと障害表現を切り離すことで、本パッケージは関心の分離を維持し、主要な設定サービスがオーケストレーションに集中できるよう配慮しつつ、エラーインフラがシステムの整合性のために必要なトレーサビリティを提供します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/config
```

## 依存関係

本パッケージはNode.js ESM環境を必要とし、Effect 4.xと完全に互換性があるように構築されています。コアとなるランタイム、スキーマ、および依存性注入の基盤としてEffectを活用しています。

開発には、共有の型定義のために`@gyomu/schema`、ベースラインとなるI/O操作のために`@gyomu/infra`を使用します。パッケージの基盤となるインフラをサポートするため、これらの主要な依存関係がプロジェクトにインストールされていることを確認してください。

## 開発

Gyomu Configuration Platformは、設定を環境変数の集まりとしてではなく、型安全なデータ契約として扱うべきであるという考えに基づいています。Effect Schemaを活用することで、検証の負担を実行時の発見から可能な限り早い段階へと移行し、無効な設定を重大なシステム障害として扱います。このアーキテクチャでは、「構築による正しさ（Correctness by Construction）」を優先しており、グローバル・ユーザー・スコープごとの設定をマージする階層的な解決戦略は、宣言的なパイプラインとして抽象化されています。これにより、アプリケーションの状態が単に「読み込まれる」だけでなく、厳密なスキーマに従っていることが証明可能となり、設定の欠落や誤りに関連する実行時のバグを根本から排除します。

コントリビューターは、設定値を提供されたスコープの純粋関数として解決する「イミュータブルな解決」の原則に従う必要があります。可能な限り副作用の大きいルックアップは避けてください。プラットフォームは決定論的かつテスト可能であるように設計されているため、ロジックは基礎となるストレージ層やトランスポート層から分離されている必要があります。新しい解決フェーズを設計する際には、未加工データの取り込みとスキーマ駆動型の正規化層との間に厳格な分離を維持してください。これにより、システムが進化してもコアとなるサービスベースのAPIは安定した状態に保たれ、最終的な平坦化された設定オブジェクトの透明性を損なうことなく、複雑な階層マージを実現できます。

## Public API

- 設定の解決 - グローバル、ユーザー、スコープごとの定義に優先順位ルールを適用し、多層的な設定取得を制御します。
- 型安全な設定アクセス - アプリケーションコンポーネントに対して、検証済みかつ型安全な設定データを提供するサービスインターフェースを公開します。
- 解決の診断 - 開発者が設定取得プロセス中の障害箇所をトラブルシューティングおよび特定するために役立つ、構造化されたエラーコンテキストを提供します。
