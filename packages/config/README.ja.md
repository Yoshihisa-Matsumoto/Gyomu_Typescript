# Gyomu Config

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomu プロジェクトに堅牢なインフラストラクチャを提供するために設計された、集中管理型の設定管理システムです。複数のソースからの設定の取得、検証、および階層的なマージを調整し、アプリケーション全体で実行環境に応じた一貫した管理を実現します。

グローバルおよびユーザーのスコープに基づいて設定を解決することで、Effect Schema による厳格な検証を行い、構造的な整合性を強制します。このアプローチにより、完全に型安全な設定が提供され、ソフトウェアエコシステム全体で信頼性が高く予測可能な動作が可能になります。

## アーキテクチャ

@gyomu/config のアーキテクチャは、設定のライフサイクルを管理する中央集権的な解決サービスを中心に構築されています。このコアコンポーネントは、グローバル、ユーザー、スコープ固有の各レベルから取得される設定の収集、階層的なマージ、およびスキーマベースの検証を調整します。解決基準を利用することで、アプリケーションの設定をライフサイクルを通じて整合性を保った型安全な構造へ統合します。

本パッケージは、調整ロジックとエラーハンドリングを分離するように構成されています。プライマリサービスレイヤーが解決プロセスを調整し、専用のエラー管理モジュールが障害を分類・診断するための構造化されたフレームワークを提供します。詳細なメタデータをキャプチャし、解決プロセスのどの段階で問題が発生したかを特定することで、このアーキテクチャは正確なエラー報告を可能にします。これらのコンポーネントは一体となって、設定の取得が予測可能で保守しやすく、障害に対して耐性を持つことを保証します。

## インストール

pnpm を使用してインストールしてください。

```bash
pnpm add @gyomu/config
```

## 依存関係

本パッケージは ESM 環境を必要とし、Effect 4.x との互換性を持つように設計されています。これは Effect エコシステム上に構築された拡張機能であり、共有型定義のために `@gyomu/schema` を、基盤となる I/O 操作のために `@gyomu/infra` を利用します。インストール前に、プロジェクトがこれらのランタイム要件をサポートするように設定されていることを確認してください。

## 開発

Gyomu の設定管理基盤は、グローバル・ユーザー・スコープの階層構造を統合し、アプリケーション全体で一貫した設定解決を提供することを目的としています。設計の核心は、複数のソースから集約された設定を、Effect Schema を用いて厳格に検証し、型安全な状態でアプリケーションへ提供することにあります。開発者は、設定ソースへ直接アクセスするのではなく、提供された ConfigResolver サービスを介してのみ設定を取得する設計を維持してください。この規約により、設定解決のライフサイクルを中央で制御し、システムの一貫性を担保します。

コントリビューターは、設定解決処理を宣言的なパイプラインとして構築し、副作用を最小限に抑えるよう努めてください。設定の追加やスコープの拡張を行う際は、既存の API を維持しつつ、型安全かつイミュータブルな設計を損なわないことが求められます。また、設定の取得失敗時には常に構造化されたエラーを返すことで、診断と復旧が可能なメタデータを保持しなければなりません。これらのアーキテクチャの原則を守ることで、将来的な拡張性を維持しつつ、システムの堅牢性を継続的に高めることを目指します。

## Public API

- Configuration Resolution - グローバル、ユーザー、およびスコープ定義全体に優先順位ルールを適用し、多層的な設定取得を調整します。
- Typed Configuration Access - 検証済みかつ型安全な設定データをアプリケーションコンポーネントへ提供するサービスインターフェースを公開します。
- Resolution Diagnostics - 設定の検索プロセス中に、開発者が障害箇所をトラブルシューティングおよび特定できるように、構造化されたエラーコンテキストを提供します。
