# Gyomu Approval Core

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステム内における複雑な承認ワークフローを管理するために必要なドメインモデル、インターフェース、およびサービス定義の基盤を提供します。高い拡張性を備え、手動および自動の両方の介入に対応できるよう設計された標準化されたアーキテクチャを確立します。

リクエストのライフサイクル、ポリシーに基づく意思決定、不変の監査履歴への統一的なアプローチを提供することで、組織のプロセス全体にわたり一貫したガバナンスを保証します。多様な実行環境において、承認要件の確実な実行と追跡を促進する堅牢なドメイン基盤として機能します。

## アーキテクチャ

本パッケージは、承認ワークフローを管理するためにドメイン駆動設計を中心としたモジュール式アーキテクチャを採用しています。システムの中核では、関心を別々のレイヤーに分離しています。ドメインモデルがリクエストとそのライフサイクル状態の構造データを定義し、コマンドスキーマが状態遷移の入力を標準化します。この明確な分離により、ビジネスロジックは特定のユーザーやシステムとのやり取りから切り離された状態に保たれます。

システムの接続性は、ポートベースの抽象化レイヤーを通じて管理され、リクエストの開始と状態の永続化のためのコントラクトを確立します。この設計により、コアロジックは外部ストレージや実行環境から独立して動作可能です。これを補完するサービスレイヤーが履歴データへの統一的なアクセスを提供し、ユーザーやツール全体で一貫した監査と記録の取得を可能にします。これらのコンポーネントを中央の入り口に集約することで、アーキテクチャは複雑な承認ワークフローを統合するための堅牢で型安全なAPIを提供し、リクエストのライフサイクル全体を通じて厳格なデータ整合性とトレーサビリティを維持します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/approval-core
```

## 依存関係

本パッケージにはESMをサポートするNode.js実行環境が必要であり、Effect 4.xとの互換性を前提として設計されています。Effectエコシステムを主要な基盤として活用しています。

機能は、Effectのランタイム、Schema、およびContextモジュールに基づいて構築されています。さらに、本パッケージは共有の型定義およびスキーマ定義として `@gyomu/schema` を利用します。本ライブラリを統合する前に、プロジェクトがESM互換の設定になっていることを確認してください。

## 開発

本パッケージは「Policy-as-Codeの独立性」という哲学に基づいて構築されており、承認ワークフローを特定のビジネス機能の副産物ではなく、分離されたインフラストラクチャサービスとして扱います。リクエストのライフサイクルを標準化されたドメインモデルに抽象化することで、システムは承認が人間のステークホルダーによってトリガーされたか、自動システムによってトリガーされたかを問わず動作可能です。このアーキテクチャ上の分離によりドメインの漏洩を防ぎ、基礎となる承認エンジンをモジュール化および合成可能な状態に保つことができます。これは、Gyomuプロジェクトの多様な要件に合わせてスケールするために不可欠です。

コントリビューターは「厳格な不変性とトレーサビリティ」の原則を遵守し、開始から最終的な解決に至るまで、すべての状態遷移を監査可能なイベントとして扱う必要があります。型安全なステートマシンと標準化された入力スキーマを通じてデータの整合性を優先し、リクエストがあいまいな状態に到達しないようにします。さらに、「コントラクトファースト」のアプローチを採用し、すべてのインターフェースにおいて即時の利便性よりも拡張性を優先する必要があります。開発者は長期的な相互運用性を重視し、新しい組織ポリシーが策定された際に、コアのドメインサービスに構造的な変更を加えることなく、評価エンジンに組み込めるようにすることが求められます。

## Public API

- 承認ワークフローモデリング - システム内の複雑な承認リクエストを表現するために必要な主要なライフサイクル、ステータス、およびチャレンジ構造を定義します。
- ポリシー評価結果 - 承認ポリシーチェックの結果を標準化し、承認、拒否、保留の各決定を明確に区別できるようにします。
- ライフサイクル管理ポート - 新しいリクエストの提出と状態管理のための抽象インターフェースを提供し、インフラストラクチャの実装からの分離を実現します。
- 監査と履歴追跡 - 過去の承認イベントの取得を可能にし、ユーザーや統合ツール向けの監査容易性とデータ分析を促進します。
