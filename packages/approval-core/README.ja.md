# Gyomu Approval Core

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuプロジェクトにおける複雑な承認ワークフローを管理するために必要な、基本的なドメインモデル、インターフェース、サービス定義を提供します。申請の追跡、評価、監査のための標準化されたコントラクトを確立し、人間による手動操作とシステムによる自動処理の橋渡しをします。ビジネスロジックを永続化から分離することで、ライフサイクル管理のための堅牢で拡張性の高い基盤を確保します。このアプローチにより、組織は多様な運用要件にわたって一貫したガバナンスを維持しつつ、統合された履歴監査を通じて完全な透明性を確保できます。

## アーキテクチャ

本パッケージは、ドメインロジック、インタラクションのコントラクト、データ管理を分離したモジュール形式のアーキテクチャで構成されています。ドメインモデルが承認リクエスト、ライフサイクル状態、決定結果の構造的な基盤を定義し、ワークフローの整合性を保ちます。コマンドスキーマはユーザーやシステムの入力を標準化し、承認や却下といったライフサイクル遷移におけるコントラクトの整合性を強制します。これらのコマンドはシステムポートと連携します。システムポートはビジネスロジックとインフラストラクチャを分離する抽象化レイヤーとして機能し、柔軟なリクエスト送信と状態の永続化を実現します。さらに、履歴管理専用のサービス抽象化も含まれており、特定のユーザーやツールに関連する監査ログの取得が可能です。システム全体は、これらモデル、コマンド、サービスを公開する中央エントリーポイントを通じて統合され、承認ワークフローの統合と管理のための統一されたAPIを提供します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/approval-core
```

## 依存関係

本パッケージには、ESMをサポートするNode.js実行環境が必要です。また、Effect 4.x向けに特別に構築されています。ランタイム、スキーマ、コンテキスト管理を含むEffectエコシステムを主要な基盤として利用します。さらに、アプリケーション全体で共有される型とデータ定義を扱うため、@gyomu/schemaと統合されています。

## 開発

本パッケージは、Gyomuプロジェクトにおける承認ワークフローのドメイン基盤として、人による承認と自動承認の双方を統合的に扱うことを目的としています。設計の核心は、承認リクエスト、ポリシー評価、ライフサイクル、および監査履歴をドメインモデルとして中心に据え、インフラストラクチャ層から完全に切り離すことにあります。貢献者は、サービスをインターフェースのみで定義し、特定の技術スタックやインフラ実装への依存を排除することで、疎結合かつ拡張性の高いドメイン設計を維持してください。

承認プロセスにおける健全性を担保するため、ライフサイクルの状態遷移は厳格に定義し、不正な操作をシステムとして排除する設計が求められます。承認結果をポリシー評価とユーザー操作として明確に分離し、それらに対する全ての操作は型安全なコマンドを通じて実行される必要があります。また、監査履歴はイミュータブルな記録として保持し、一貫したアイデンティティとコンテキストの追跡を保証することで、変更履歴を一切損なわない信頼性の高いドメインモデルの進化を追求してください。

## Public API

- Approval Lifecycle Management - 承認リクエストの開始から最終的な解決までのエンドツーエンドのステータスをモデル化し追跡します。
- Decision Evaluation Framework - 承認ポリシーチェックに対する構造化された結果を定義し、追加の承認や拒否の要件を規定します。
- Interaction Ports - リクエスト送信および状態永続化のための標準化されたインターフェースコントラクトを提供し、様々なバックエンドとの統合を可能にします。
- Auditing and History - ユーザーやツールに関連する過去のイベントや承認記録の取得と管理を可能にします。
- Command Input Schemas - 承認ワークフローに対する一貫したユーザーおよびシステム間のインタラクションに必要なパラメータ構造を標準化します。
