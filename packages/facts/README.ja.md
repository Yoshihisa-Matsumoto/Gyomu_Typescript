# Gyomu Facts

[US English](README.md) | JP 日本語

## 概要

本パッケージはGyomuエコシステムの分析エンジンとして、生のプロジェクトメタデータを構造化されたインサイトに変換します。その主な目的は、リポジトリの事実を型安全かつ一貫性を持って取得、参照、管理するための堅牢な基盤を提供することです。

本フレームワークは、安定したプロジェクト定義と、ブランチやワーキングツリーのような一時的な状態を分離することで、アプリケーションが開発コンテキストを一貫して把握できるようにします。統合されたプロバイダーインターフェースを通じてディレクトリ構造を評価・ランク付けし、コードベース全体におけるアーキテクチャ上の重要度を判定することで、複雑なプロジェクト環境から意味のある構造化されたインテリジェンスを引き出すことが可能になります。

## アーキテクチャ

本アーキテクチャは、すべての分析プロセスのエントリポイントとなる中央オーケストレーション層を中心に構成されています。このルート層は内部モジュールを集約して統一されたインターフェースを提供し、ファイルシステム上の未加工データを構造化されたクエリ可能なメタデータへと変換します。

分析の中核となるロジックは、パッケージ構造の評価を担う専用モジュール内に局所化されています。これらのコンポーネントはメタデータスキーマを定義し、ディレクトリ階層の定量的重要度スコアを算出するアルゴリズムを実装します。ファイルシステムの情報を構造化された事実へ変換することで、ディレクトリの重要度をランキングし、後続のアーキテクチャ評価に信頼できる基盤を提供します。

内部の連携により、パッケージ情報の抽出からスコアリングおよびランキングロジックの適用に至るまで、分析データが確実にフローします。この設計では、外部クエリのオーケストレーションと構造コンポーネントの専門的な評価が分離されており、データモデリングとプロジェクト構成の分析評価を明確に区別しています。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/facts
```

## 依存関係

本パッケージは、ESMを使用するNode.js実行環境向けに設計されており、コアとなるランタイム基盤としてEffect 4.xを必要とします。堅牢な型定義、インフラストラクチャの処理、およびTypeScriptの解析機能を提供するために、@gyomu/schema、@gyomu/infra、@gyomu/ts-analysisを活用しています。本パッケージは最新のモジュール解決とEffectエコシステムの最新のランタイム機能に依存しているため、インストール前にプロジェクトがESM互換の設定になっていることを確認してください。

## 開発

本パッケージは、Gyomu プロジェクトにおける開発コンテキストを構造化し、型安全な方法で提供するための基盤です。その中核となる設計意図は、プロジェクト固有の永続的な情報（Project Facts）と、ブランチやワーキングツリーに依存する動的な情報（Repository Facts）を概念的に分離して管理することにあります。この分離により、情報の性質に応じた適切なライフサイクルを維持し、アプリケーションが開発環境の現在状態を一貫して理解できる設計を実現します。開発者は、すべての情報を共通の `Fact` モデルとして定義し、それらを `FactSet` を用いて型安全な集合として扱う必要があります。情報の取得は必ず `FactProvider` を経由することで、利用側が個別の実装詳細に依存することを防ぎます。新しい事実を追加する際は、既存の `FactProvider` 利用者に影響を与えない拡張性を維持し、暗黙的な型変換を排除した宣言的かつ型安全なモデル定義を徹底してください。これにより、構造化されたデータの一貫性を保ちながら、システムが長期的に拡張可能な状態を維持することが求められます。

## Public API

- プロジェクト構造解析 - プロジェクト構成に関するメトリクスとメタデータを算出し、構造の深い理解を可能にします。
- 重要度スコアリング - ディレクトリ構造に定量的な値を割り当て、プロジェクト階層内での相対的な重要度と優先順位を決定します。
- ファクトモデリング - パッケージの状態を、後続のアーキテクチャツールで使用可能なクエリ可能なファクトの集合として表現します。
