# Gyomu TSDoc

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuプロジェクト向けの堅牢なドキュメント管理インフラストラクチャを提供します。TypeScriptのソースコードとTSDocコメントを継続的に同期させることで、コードベースの変更に追従した正確なドキュメントを維持します。システムはプロジェクトのステートスナップショットと高度なファイル変更検知を利用し、正確かつ自動化された更新を実現します。ドキュメント生成と変更検知・適用を分離することで、保守性と一貫性を重視した信頼性の高いフレームワークを提供し、開発者が自信を持って正確にドキュメントのライフサイクルを管理できるようにします。

## アーキテクチャ

本アーキテクチャは、JSDocドキュメントの一貫性を維持するために連携する4つの主要な機能ドメインで構成されています。システムはスナップショットメカニズムに依存しており、ファイルハッシュやメタデータを通じてプロジェクトの状態を追跡することで、モノレポ環境内での構造的な変更を正確に特定します。安定したデータモデルがプロジェクトの識別情報とワークスペース設定を定義し、ライフサイクル全体を通じて信頼性の高い対話を実現します。集中管理されたパスユーティリティは、ファイルシステムパスを正規化し、ソースコードとビルド成果物間の関係をマッピングすることで、一貫したリソース識別を実現する基盤となります。このマッピングにより、ドキュメントの計画、統合、レンダリングを管理する更新ワークフローのオーケストレーションが可能になります。スナップショットベースの変更検知プロセスを構造化されたマージ計画と統合することで、JSDocコメントが正確に生成され、適切なソースファイルに適用されることを保証します。ルート層はこれらの機能を統合されたAPIを通じて公開し、状態追跡とドキュメント更新サイクル間の対話を調整します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/tsdoc
```

## 依存関係

本パッケージはNode.jsを必要とし、Effect 4.xをコアランタイムとして利用するESM環境向けに設計されています。型安全性と関数型アーキテクチャを確保するため、スキーマ管理やコンテキスト操作にはEffectエコシステムを活用します。

本プロジェクトは、共通型定義のための`@gyomu/schema`、I/O操作のための`@gyomu/infra`、LLM駆動タスクのための`@gyomu/ai-compiler`といった内部基盤ライブラリと統合されています。インストール前に、TypeScriptおよびESMに対応した環境設定を行ってください。

## 開発

本パッケージは、Gyomuにおけるソースコードドキュメント管理の信頼性を担保するため、ソースコードとTSDocコメントを単なるテキスト以上の「同期された成果物」として定義します。この設計の中核には、コードの状態を永続的なSnapshotとして管理する手法があります。これにより、システムは変更検出の際に常に確実なベースラインを参照でき、コードの進化に伴うドキュメントの乖離を排除します。開発者は、ソースコードの変化を追跡可能なイベントとして扱い、プロジェクトの整合性を維持する責務を負います。

アーキテクチャ上の決定事項として、ドキュメントの生成ロジックと、その変更をソースコードへ適用するプロセスを明確に分離します。変更検出エンジンが特定した差分は、まず「更新計画」として出力され、その後で検証可能な形式でファイルシステムへ反映されます。このパイプライン構造により、不必要なファイル操作を抑え、再現性の高い更新処理を実現します。モノレポ環境においても、正規化されたパスモデルと一貫したワークスペースメタデータを用いることで、プロジェクト全体で統一されたドキュメント管理基盤を維持してください。

## Public API

- プロジェクト状態の追跡 - ファイルシステムのスナップショットをキャプチャ、コミット、差分比較することで、プロジェクトの反復間での変更を検知します。
- JSDocの自動化 - 構造化されたマージプランを既存のソースファイルに適用し、JSDocコメントの生成と同期を自動化します。
- パス解決ユーティリティ - パスの正規化や、ソースファイルとそれに対応するビルド成果物間の関係をマッピングするためのツールを提供します。
