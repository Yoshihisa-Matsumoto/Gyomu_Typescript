# Gyomu TSDoc

[US English](README.md) | JP 日本語

## 概要

本パッケージは、TypeScriptプロジェクトにおけるJSDocドキュメントの管理と同期を行うための堅牢な自動化フレームワークを提供します。Gyomuのドキュメント管理基盤として機能し、ソースコードとTSDocコメントの継続的な整合性を維持します。

本システムは、永続的なスナップショットを通じてプロジェクトの状態を追跡し、計算された更新を適用することでドキュメントのライフサイクルを管理します。ドキュメント生成、変更検知、更新適用を分離することで、安全で再現性が高く、保守性に優れたコードドキュメント管理を実現します。これにより、ソースコードの変更に応じてドキュメントが自動的かつ正確に更新され、手動メンテナンスの負担が軽減されます。

## アーキテクチャ

本パッケージのアーキテクチャは、ドキュメント同期のライフサイクルを管理する複数のドメインで構成されています。ルートエントリポイントは、スナップショット管理、パスユーティリティサービス、ドキュメント更新エンジンの統合を制御します。このモジュール設計により、状態追跡、ファイル解決、コード修正の各プロセスが分離されつつも、相互運用可能になっています。

スナップショットコンポーネントは、ファイルハッシュやワークスペース識別子を用いて永続的なプロジェクト状態を保持することで、確定的な追跡を実現します。現在のスナップショットと履歴データを比較して構造的な変更を特定し、ドキュメント更新のトリガーとして機能します。

パスユーティリティは基礎レイヤーを提供し、ソースファイルとビルド成果物間の信頼性の高い双方向マッピングを保証します。この正規化は、スナップショット処理と更新エンジンの両方において極めて重要です。最後に、更新コンポーネントがJSDocのライフサイクルイベントのオーケストレーションを行います。コード解析データを構造化されたドキュメントへと変換し、一連の計画的な編集を通じて既存のソースファイルと新しいコンテンツを整合させることで、プロジェクトの進化に合わせてドキュメントの同期を維持します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/tsdoc
```

## 依存関係

本パッケージはESM環境向けに設計されており、Effect 4.x以降を必要とします。ランタイム、スキーマ管理、コンテキストハンドリングの核心部分をEffectエコシステムに依存しています。

機能は、共通型を扱う `@gyomu/schema` や基礎的なI/O操作を行う `@gyomu/infra` といった内部インフラストラクチャライブラリに基づいて構築されています。さらに、Concept生成などのLLM主導のタスクを促進するために `@gyomu/ai-compiler` が使用されています。

## 開発

本パッケージは、Gyomuにおけるソースコードドキュメント管理の構造化された基盤として設計されています。主な目的は、TypeScriptコードとTSDocコメントを継続的に同期状態に保ち、ドキュメントを静的な成果物からコードベース内の動的なバージョン管理コンポーネントへと変換することです。TSDocをソースコード構造の不可欠な要素として扱うことで、実装と記述メタデータの間で高い忠実度を維持し、ドキュメントがロジックとともに進化することを保証します。

アーキテクチャ面では、ドキュメント更新の計画と、それらをソースファイルへ実際に適用する処理を厳格に分離しています。これを維持するため、貢献者はすべてのプロセスが永続的なスナップショットメカニズムを通じて実行されるようにする必要があります。このメカニズムはプロジェクト状態をキャプチャし、正確な変更検知と最小限の対象を絞った更新を可能にします。ファイルパス解決からフォーマットされたJSDocの注入に至るまで、すべての操作は正規化されたパスモデルに従う必要があり、これによりモノレポを含む複雑な環境全体で信頼性が確保されます。開発者はモジュール性を優先し、ドキュメント生成、変更検知、整合化が分離された状態を維持することで、長期的な保守に向けた予測可能で検証可能かつ再現性の高いワークフローを提供してください。

## Public API

- プロジェクト状態追跡 - プロジェクトファイルのスナップショットをキャプチャ、コミット、比較することで、経時的な構造変化を検知できます。
- ドキュメント更新のオーケストレーション - JSDoc更新の計画、マージ、適用を自動化し、ドキュメントをコードの変更と同期させます。
- パス管理ユーティリティ - ファイルパスを正規化し、ソースとビルド出力場所の間でマッピングを行うツールを提供し、一貫したファイルベースの操作をサポートします。
