# Gyomu Concept

[US English](README.md) | JP 日本語

## 概要

本パッケージは、TypeScriptプロジェクトのアーキテクチャ構造をモデル化するための主要なエンジンとして機能します。ファイルシステムの生のデータを、設計意図、運用上の知識、コアとなる責務を表現した構造化された高レベルなプロジェクトモデルへと変換します。

ソースコード解析から得られた知見と、人間が管理する専門知識を統合することで、開発者とAIの両方が利用可能な統合ナレッジベースを作成します。その目的は、プロジェクトモデルを静的なドキュメントではなく生きている資産として標準化し、プロジェクトのライフサイクルを通じてアーキテクチャの一貫性を保ち、複雑な技術知識の継続的なメンテナンスを促進することにあります。

## アーキテクチャ

本パッケージは、ファイルシステム上のデータをアーキテクチャモデルとドキュメントへと変換する専門的な機能ドメインで構成されています。このアーキテクチャは、構造解析、概念モデリング、自動出力生成という懸念事項を分離することで、デカップリングされたモジュール式のシステムを実現しています。中心となる解析レイヤーは、ディレクトリとパッケージのモジュールで構成されます。ディレクトリコンポーネントはファイルレベルのプロパティと階層を特定し、パッケージモジュールはソースのエクスポートと依存関係を解決して、一貫性のある包括的なアーキテクチャモデルを構築します。これらのコンポーネントは、未加工のメタデータをプロジェクト構造を定義する正式な概念表現へと統合することで連携します。ドキュメントレイヤーは、これらの概念モデルを開発者向けコンテンツへと変換するプロセスを統括します。専用のアセンブリパイプラインを活用してプロジェクトデータの統合、ローカライズの管理、構造の検証を行います。データ取得とレンダリングを分離することで、ドキュメントが進化し続けるプロジェクト構造と同期し続け、ソースコードと概念ドキュメントの間の信頼できる橋渡しを提供します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/concept
```

## 依存関係

本パッケージはESM環境を必要とし、Effect 4.x向けに構築されています。プロジェクトがモダンなJavaScriptモジュールとEffectランタイムをサポートするように設定されていることを確認してください。

本ライブラリは、スキーマおよびコンテキスト管理の主要な基盤として`effect`を利用しています。また、内部インフラストラクチャのコンポーネントと密接に統合されており、具体的には共通型定義のために`@gyomu/schema`を、I/O操作のために`@gyomu/infra`を、そして自動ドキュメント生成やLLMベースのコンパイル処理をサポートするために`@gyomu/ai-compiler`を使用します。

## 開発

`@gyomu/concept` は、プロジェクトのナレッジを構造化された永続的なモデルへと変換し、開発者とAIエージェントの双方にとって信頼できる唯一の情報源として機能するように設計されています。ソースコード解析によるナレッジの収集とドキュメントの生成を分離することで、アーキテクチャの洞察、責務の境界、設計意図を出力形式に関わらず一貫して保持します。コントリビューターは、モデルの構造的整合性を維持し、機械由来の洞察と人間が提供するメタデータを、それぞれの来歴を損なうことなく統合できるように中立性を保つ必要があります。

本パッケージを拡張する際は、コード解析、Conceptの構築、ドキュメント生成の関心の分離を厳格に適用してください。新機能の開発においては、永続モデルに対する差分更新を優先し、プロジェクトの進化に合わせて基盤となる `Concept` が再作成されるのではなく、洗練されていくようにします。すべての構造的概念化は、定義されたスキーマに基づいて検証し、個別のパッケージからプロジェクト全体のスコープに至るまで、粒度を問わず一貫性を保つ必要があります。これらの原則を遵守することで、アーキテクチャは静的なドキュメントではなく、プロジェクトの進化を体現する堅牢な表現であり続けます。

## Public API

- パッケージの概念化 - TypeScriptプロジェクトの構造を包括的なアーキテクチャモデルに変換し、主要なコンポーネントと外部依存関係を特定します。
- ドキュメント生成 - 分析されたプロジェクトデータに基づいて、プロジェクトのREADMEファイルの構築、ローカライズ、レンダリングを自動化します。
- ディレクトリ分析 - ファイルシステム構造を調査し、ディレクトリ内容と内部階層のメタデータ豊富な表現を生成します。
