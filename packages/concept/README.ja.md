# Gyomu Concept

[US English](README.md) | JP 日本語

## 概要

本パッケージは、コードベースの生のデータと高レベルの構造モデルの溝を埋めることで、プロジェクトの知識を管理するためのアーキテクチャの基盤を提供します。自動化されたコード解析と人間が維持するインサイトを統合することで、プロジェクトのアーキテクチャ、責務、そして設計意図の統一された表現を作成します。

その目的は、静的なドキュメントから、人間とAIの両方にとっての共有知識ベースとなる、構造化されたライブモデルへと移行することにあります。このアプローチにより、プロジェクトのライフサイクルを通じて技術的なコンテキストが一貫して維持され、チームは複雑な設計Conceptを信頼性が高く進化し続けるプロジェクトモデルとして形式化できるようになります。

## アーキテクチャ

本パッケージは、構造解析、メタデータ管理、ドキュメント合成という3つの主要な機能ドメインを中心に構成されています。これらの責務を分離することで、アーキテクチャはTypeScriptのコードベースを形式的な概念モデルへ変換しつつ、設計意図と物理的なファイル構造の間の厳密な同期を維持します。

解析エンジンはpackageモジュールとdirectoryモジュールに配置されており、これらが連携してモジュールのエクスポートの解決、依存関係のマップ、構造的エンティティの定義を行います。これらのコンポーネントはファイルシステムからアーキテクチャ上のプロパティを抽出し、それらを検証することで、生成されるメタデータがプロジェクトの構成を正確に反映するようにします。

最終的に、ドキュメントモジュールがこれらの構造モデルを利用してプロジェクトのアセット生成を自動化します。Markdownコンテンツの組み立て、ローカライズ、レンダリングを調整し、検証済みのアーキテクチャメタデータを標準化されたドキュメントへと変換します。このパイプラインにより、コンテンツの組み立てと構造的な整合性の両方を検証する統合テストに支えられ、ドキュメントがコードベースと常に一致した状態に保たれます。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/concept
```

## 依存関係

このプロジェクトはESMをサポートするNode.js実行環境を必要とし、Effect v4を基盤として構築されています。開発ライフサイクル全体で型安全を確保するために、TypeScriptとシームレスに動作するように設計されています。

本パッケージは、ランタイム、スキーマ管理、コンテキスト処理の核としてEffectエコシステムに依存しています。さらに、標準化されたインフラストラクチャ、共有データ型、LLM駆動の開発ユーティリティを提供するために、内部パッケージである@gyomu（具体的には @gyomu/schema、 @gyomu/infra、 @gyomu/ai-compiler）と統合されています。

## 開発

@gyomu/conceptは、プロジェクトにおけるアーキテクチャや設計意図、運用知識を「ドキュメント」としてではなく、人間とAIの双方が解釈可能な「構造化された知識モデル」として定義するために設計されています。開発者は、ソースコードから抽出された機械的な事実と、人間が意図的に付与する設計コンテキストを切り離して管理し、それらをConcept上で統合することで、プロジェクトの「知識の真実」を一元管理します。この中立的な知識表現は、あらゆる出力形式や言語への変換基盤となり、プロジェクトのライフサイクル全体を通じて一貫性を保つための唯一の情報源となります。

貢献者は、ソースコード解析、Conceptの構築、そしてドキュメント生成という各工程を独立した責務として扱い、システムを拡張する必要があります。Conceptの構築においては、パッケージやディレクトリといった各粒度の構造を同一のモデルで扱うことが求められ、情報の永続化と差分更新を前提とした設計を維持してください。人が管理する知識とコードから導出された知識の出所を厳密に保持しながら統合することで、コードの変更とドキュメントの乖離を防ぎ、プロジェクトの知識が常に最新かつ正確な状態に保たれるアーキテクチャを追求してください。

## Public API

- プロジェクト構造モデリング - TypeScriptのディレクトリおよびパッケージの構造を、形式的かつ永続的な概念メタデータに変換します。
- 自動ドキュメント生成 - コードベースの構造データを、READMEファイルなどの標準化されローカライズされたドキュメントアセットに変換します。
- アーキテクチャインサイトの合成 - プロジェクトの依存関係グラフとソースのエクスポートを解析し、パッケージの境界やアーキテクチャ構成に関するインサイトを生成します。
