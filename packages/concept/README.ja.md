# Gyomu Concept

[US English](README.md) | JP 日本語

## 概要

本パッケージは、生のソースコードや依存関係情報を一貫性のあるプロジェクトモデルへ変換するオーケストレーション層として機能します。プロジェクトのアーキテクチャ、設計意図、運用知識を構造化されたモデルとして表現することで、技術的な成果物と人間の理解との間のギャップを埋めます。

そのミッションは、これらのモデルの作成と保守を容易にし、人間とAIの両方にとっての統合された知識ベースを提供することです。自動化されたコード解析と人間による洞察を統合することで、プロジェクトの知識がコードベースと並行して進化し、整合性を保つことを確実にします。開発ライフサイクル全体を通じて、効果的なコミュニケーションと長期的なアーキテクチャの整合性を維持するための基盤として機能します。

## アーキテクチャ

@gyomu/conceptのアーキテクチャは、生のソースコードから包括的なアーキテクチャドキュメントへの移行を促進する3つの専門ドメインで構成されています。`src/package`および`src/directory`コンポーネントは解析エンジンとして機能し、ソース構造の検査、エクスポート対象の解決、プロジェクトメタデータおよび依存関係に基づく永続的な概念モデルの合成を担当します。

構造データが確立されると、`src/readme`コンポーネントがドキュメントのオーケストレーション層として機能します。合成されたモデルを使用してプロジェクトドキュメントを組み立て、ローカライズし、レンダリングします。このプロセスは、Markdownコンテンツの最終的な出力への変換を管理する専用のビルドコンテキストに依存しています。ライフサイクル全体を通じて、統合された検証フローにより、生成されたドキュメントが基礎となる概念モデルと構造的に整合していることが保証され、プロジェクトの物理的な実装とドキュメント化されたアーキテクチャとの間の整合性が維持されます。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/concept
```

## 依存関係

本パッケージはESM環境を必要とし、Effect 4.x向けに構築されています。ランタイム、スキーマ検証、依存性注入においてEffectエコシステムに依存しています。

中核機能は、共有型定義を提供する`@gyomu/schema`、基盤となるI/O操作を行う`@gyomu/infra`、LLM統合タスクを行う`@gyomu/ai-compiler`といったいくつかの内部ライブラリによって支えられています。互換性を維持するため、インストール前にプロジェクトがEffect 4.x向けに設定されていることを確認してください。

## 開発

@gyomu/conceptは、進化し続けるソースコードとプロジェクトの構造的な意図との間の権威ある架け橋として機能するように設計されており、生のファイルを永続的で構造化された知識モデルに変換します。コントリビューターは、このモデルの整合性を優先し、派生したコードメタデータと人間が記述した設計意図を統合する、技術に依存しない表現であり続けることを保証しなければなりません。本パッケージは、知識はレガシーなドキュメントに分散させるのではなく、統合された構造に格納されるべきであるという原則に基づいています。そのため、すべてのコントリビューションは、この中心的な永続モデルをアーキテクチャおよび運用上のインテリジェンスの唯一の正当なソースとして維持するという目標を強化するものである必要があります。

本パッケージ内の開発においては、ソース解析、Concept合成、ドキュメント生成の懸念の分離を厳格に順守しなければなりません。コードベースを修正する際、コントリビューターは、データの出所を維持しつつ、個々のパッケージからプロジェクト全体に至るまで、あらゆる粒度レベルで`Concept`の構造的整合性が保持されるようにする必要があります。新機能や改善は、人間が管理する知識とコードから派生したメタデータの自動調整をサポートし、モノリシックな生成フローに頼ることなく、継続的で差分ベースの更新が可能なシステム拡張性を確保しなければなりません。

## Public API

- Package Conceptualization - プロジェクト環境を解析し、パッケージの依存関係、エクスポート、アーキテクチャの意図の構造化モデルを構築します。
- Directory Analysis - ディレクトリの内容を再帰的に評価し、個々のコード単位の構造的役割を記述するメタデータを生成します。
- Automated Documentation - コードベースから導出された概念モデルから直接、Markdownドキュメントを生成、ローカライズ、レンダリングします。
