# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomu エコシステム全体におけるドメインモデリング、バリデーション、およびエラーハンドリングのための堅牢なスキーマ駆動型基盤を提供します。共有スキーマ、型、およびサービス定義を一元管理することで、データ整合性とレイヤー間の整合性のあるやり取りを保証する信頼性の高い通信レイヤーを確立します。

その目的は、パッケージ間の疎結合を維持しつつ、厳格な型安全性を確保するための基本的な契約を提供することです。Effect エコシステムを活用することで、ビジネスロジックを標準化し、CRUD パターンを自動化し、プロジェクト全体で信頼性とモジュール性を促進する統合的なアーキテクチャを実現します。

## アーキテクチャ

アーキテクチャは、データ整合性と標準化された運用ロジックを強制する5つの機能レイヤーで構成されています。エンティティ層とドメインスキーマ層は定義の中心となり、ビジネスモデルの構造的基盤と CRUD パターンを確立します。一方、TypeScript 解析層はイントロスペクション（自己検査）やドキュメント生成に必要なメタデータを提供します。

これらのコンポーネントは、システム全体で一貫した診断特性や、リトライ・ログ記録などの運用ポリシーを適用する中央集権的なエラーハンドリングシステムによって支えられています。コアインフラストラクチャ層は、標準化された Result パターンやスキーマベースのバリデーションツールなど、レイヤー間の通信を統一する低レベルのユーティリティ機能を提供します。これらの層は一体となって、エンティティ定義、バリデーションルール、構造的メタデータが相互に作用し、アプリケーション全体で型安全性と一貫した振る舞いを保証する凝集されたエコシステムを形成しています。

## インストール

pnpm を使用してインストールしてください。

```bash
pnpm add @gyomu/schema
```

## 依存関係

本パッケージは ESM 環境向けに設計されており、コアランタイムとして Effect v4.x を必要とします。型安全なスキーマと依存性注入のために Effect を活用し、`date-fns` を使用して日付および時刻のユーティリティを堅牢に扱います。インストール前に、プロジェクトが ESM 用に設定されており、Effect エコシステムの最小バージョン要件を満たしていることを確認してください。

## 開発

このパッケージは、Gyomu プロジェクト全体で一貫性と型安全性を維持するための「共通契約（Contract）」の集約点として機能します。プロジェクト全体で利用されるドメインスキーマ、ブランド型、およびサービスインターフェースを集中管理することで、各パッケージが互いに直接依存することなく、定義されたスキーマを介して疎結合に連携できる基盤を提供します。貢献者は、データ構造やサービス定義がプロジェクト全体の標準となることを意識し、再利用性を最大限に高める設計を求められます。

実装においては、すべてのデータ定義に Effect Schema を採用し、ランタイムでのバリデーションと、AI による解析やドキュメント生成を支える詳細なメタデータ付与を必須とします。エラーハンドリングや運用基盤は共通のトレイトとResultパターンに基づいて設計し、ユーティリティは他パッケージへ依存しない純粋関数として実装してください。サービス定義はインターフェースと Context Tag に限定し、実装詳細を含めないことで、宣言的かつイミュータブルなインターフェースの維持を徹底することがこのパッケージを進化させる上での原則となります。

## Public API

- ドメインエンティティモデリング - ビジネスエンティティの定義、および包括的な CRUD スキーマ、UI アノテーション、バリデーションロジックの自動生成を可能にします。
- 構造化エラーフレームワーク - 一貫した障害報告のために、標準化されたコンテキスト、動作トレイト、リトライポリシーを備えた階層型エラーシステムを提供します。
- コード解析エンジン - TypeScript のシンボル、型、依存関係からリッチな構造的メタデータを抽出し、コードを認識したツール開発やドキュメント生成を容易にします。
- データバリデーションおよび変換 - 入力データを検証済みモデルへ安全に変換し、高度なエラー解決やバリデーション結果の平坦化をサポートします。
- 運用インフラストラクチャ - ポーリング、ロギング、標準化された Result 処理、セキュリティを考慮したパス解決など、システムオーケストレーションに必要なユーティリティを提供します。
