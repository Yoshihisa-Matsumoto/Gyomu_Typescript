# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

本パッケージはGyomuプロジェクトの基盤層であり、共有スキーマ、型定義、サービスコントラクトを提供します。ドメイン駆動のデータモデリングのための統一フレームワークを確立することで、厳格な型安全性とアーキテクチャの一貫性を維持しながら、独立したモジュール間での堅牢な連携を実現します。

Effectエコシステム上に構築されたこのツールキットは、自動的なCRUDスキーマ生成を促進し、複雑なドメイン検証を管理します。共通の構造的コントラクトを強制することで、システム全体でのデータ整合性と標準化されたAPI結果を保証します。このアプローチにより、開発者は信頼性の高い構造解析ツールや一貫したエラー診断ツールを利用でき、パッケージ間でのシームレスな対話が可能になります。

## アーキテクチャ

本パッケージのアーキテクチャは、Effectを活用して堅牢かつ型安全なデータモデリングを行う5つの機能ドメインで構成されています。**Entity**および**Gyomu**モジュールは主要なドメイン層として機能し、正式なビジネススキーマを定義してCRUD操作の生成を自動化します。これらの層は、静的解析とドキュメント化をサポートするためにコードのメタデータをモデル化する**TypeScript analysis**ユーティリティに依存しています。

これらのドメイン構造を支える**Error**モジュールは、集中管理型の診断フレームワークを提供します。エラーメタデータや、リトライロジック、重大度分類といった運用ポリシーをカプセル化し、システム全体での一貫した障害報告を保証します。このエラー戦略はスキーマベースのデコード処理に統合されており、検証上の問題をドメインモデルに直接マッピングします。

**Core**インフラ層はパッケージ全体の基盤を提供します。標準化された結果パターン、JSON構造定義、網羅的な型チェックなどの汎用ユーティリティを供給します。これらのコンポーネントを統合することで、パッケージはアプリケーションのライフサイクル全体を通じて、構造的な整合性と一貫したデータ変換ロジックを維持します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/schema
```

## 依存関係

本パッケージはNode.jsを必要とし、ESM環境向けに設計されています。Effect 4.x上に構築されており、Effect Runtime、Schema、Contextを含むEffectエコシステムを主要な基盤として利用します。

日付および時刻操作については、堅牢なユーティリティサポートのため`date-fns`に依存しています。プロジェクト環境がESMをサポートするように構成され、パッケージの機能を効果的に利用するために必要なEffectの依存関係がインストールされていることを確認してください。

## 開発

本パッケージの開発哲学は「コントラクトファーストアーキテクチャ」という原則に根ざしており、共有スキーマがGyomuエコシステム全体における唯一の正当な情報源（Single Source of Truth）となります。コアとなるドメインモデルと検証ロジックを集中管理することで、サービス間における手動同期の脆弱性を排除します。この構造は、ビジネス上の意図と実装の詳細を切り離すように設計されており、TypeScriptインターフェースが単なる受動的な型定義としてではなく、パッケージ境界を越えて一貫性を強制する能動的で検証可能な設計図として機能するようにします。

貢献者は厳格な型安全性と不変性を優先し、すべての共有定義を厳密な後方互換性を要求する不変のコントラクトとして扱う必要があります。この哲学では、継承よりも構成を、データ変換においては関数型の純粋性を重視し、共有ユーティリティが副作用のない予測可能なものであることを保証します。私たちは「失敗を早期かつ明示的に行う（fail-fast and explicitly）」という考え方に従っており、診断コンテキストやエラーハンドリングは、後付けではなくスキーマ層に組み込まれている必要があります。最終的に、貢献者はドメインの漏洩を最小限に抑えるよう努めるべきです。本パッケージは、特定の消費側サービスの運用要件を前提とせず、システムの基礎となるボキャブラリーを提供する軽量なものでなければなりません。

## Public API

- Entity Modeling - ドメインエンティティとそのフィールドの定義。自動スキーマ生成およびUIアノテーションの基盤を提供します。
- CRUD Schema Generation - 中央のエンティティ定義に基づいた、挿入、更新、選択操作のための検証済みスキーマの自動生成。
- Structured Error Handling - リトライ可能性やオブザーバビリティをサポートし、システム層全体にわたる一貫したエラー分類および診断メタデータの注入。
- TypeScript Analysis Framework - 自動化ツール向けに、シンボル、依存関係、型構成を含むTypeScriptソースコードメタデータの構造的モデリング。
- Validation and Conversion - Effectベースのスキーマとカスタム型ガードを使用した、データ入力のデコード、変換、検証のためのツール。
- Operational Infrastructure - 結果処理、JSONスキーマ構造、ログ記録、実行時環境のための基礎的なユーティリティ。
