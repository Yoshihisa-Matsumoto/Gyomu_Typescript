# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

本パッケージはGyomuプロジェクトの基盤フレームワークであり、共通のスキーマ、型定義、サービスコントラクトを提供します。システム全体において情報の中心となることで、すべてのコンポーネント間で構造の一貫性と堅牢な型安全性を維持します。

本パッケージは、標準化されたデータコントラクトと運用上のエラーパターンを定義することで、サービス間の疎結合で円滑な連携を促進します。複雑なデータ変換や体系的な診断ワークフローをサポートし、厳格なバリデーションを強制しつつ統一されたドメインモデリングを実現します。最終的に、このインフラストラクチャは、プロジェクトのエコシステム全体で一貫性と信頼性の高い開発環境を維持するために必要なアーキテクチャを提供します。

## アーキテクチャ

アーキテクチャは、コアインフラストラクチャ、ドメイン固有のエンティティ管理、高度なコード解析機能を分離する階層構造で構成されています。`core`ディレクトリは、標準化された結果パターンやJSONシリアライズプロトコルなどの基盤となるユーティリティを提供し、システム全体で一貫した通信を保証します。このベースレイヤーは、診断コンテキストと運用ポリシーを一元管理し、システム全体の信頼性を維持するエラーインフラストラクチャをサポートしています。

ドメインロジックは主に`entity`および`schemas`ディレクトリで処理されます。`entity`レイヤーは、再利用可能なフィールド定義を使用してビジネス構造をモデル化し、CRUDスキーマスイートを自動生成する主要な設定ソースとして機能します。これを補完するものとして、ビジネスプロセスの検証ルールを適用する`schemas/gyomu`ディレクトリと、シンボル解析や依存関係マッピングのための堅牢なメタプログラミングツールを提供する`schemas/typescript`ディレクトリがあります。これらのコンポーネントを組み合わせることで、静的コード解析と動的な運用要件を橋渡しする、予測可能なスキーマ駆動型の環境が実現されます。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/schema
```

## 依存関係

本パッケージはESM環境を必要とし、Effect 4.x向けに構築されています。ランタイム、スキーマ、およびコンテキスト管理の基盤としてEffectを活用し、日付と時刻のユーティリティとしてdate-fnsを利用しています。インストール前に、プロジェクトがESM向けに設定されており、Effectのバージョン要件を満たしていることを確認してください。

## 開発

本パッケージは、Gyomu プロジェクトにおける型安全性と一貫性を担保する「共通契約（Contract）」の基盤として位置づけられます。すべての共有データ、永続化対象、および検証が必要なデータは Effect Schema を用いて定義し、AI によるコード・ドキュメント生成を最適化するために、すべての Annotation を網羅的に記述することが求められます。ブランド型についても同様に本パッケージで一元管理することで、パッケージ間の境界を越えた厳格な型整合性を保証します。サービス定義に関しては、実装を含まないインターフェースと Context Tag のみに役割を限定し、各パッケージが疎結合に連携できる設計を維持してください。提供するユーティリティは、他パッケージへの依存を排除した純粋関数として実装し、常にイミュータブルかつ宣言的なインターフェースを保持することが原則です。エラー型や API の通信プロトコルについても共通の構造を厳守することで、システム全体の予測可能性を高める設計指針としています。

## Public API

- ドメインエンティティモデリング - 複雑なビジネスエンティティを定義するための包括的なツール。自動CRUDスキーマ生成および構造化されたUIアノテーションをサポートします。
- 集中管理型エラーインフラストラクチャ - システム全体で自動ログ出力やリトライロジックを支える、一貫性のあるエラー分類と診断コンテキスト管理機能。
- TypeScriptコード解析 - シンボル解析、JSDoc解析、モジュールレベルの依存関係マッピングなど、TypeScriptの構造を検査するためのフレームワーク。
- 標準化されたデータバリデーション - データの整合性を保証し、複雑なスキーマエラーに対して開発者が扱いやすい診断メッセージを提供する基礎的なバリデーションパターン。
- 公開APIコントラクト管理 - 内部ロジックを予測可能な成功および失敗レスポンスを持つ結果ベースのスキーマとしてラップするためのユーティリティ。
