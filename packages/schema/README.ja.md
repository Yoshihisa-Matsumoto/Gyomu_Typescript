# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

本パッケージはGyomuエコシステムの基盤層であり、共有スキーマ、サービス定義、およびユーティリティツールを確立します。共通のコントラクトを一元化することで、一貫した型安全性を確保し、プロジェクト内のすべてのコンポーネント間での疎結合な通信を促進します。

このフレームワークは、ドメインエンティティ、インフラストラクチャサービス、およびアプリケーションメタデータをモデル化するための堅牢な実行環境を提供します。Effectスキーマを活用することで、システム全体において信頼性の高いデータバリデーションと体系的なエラーハンドリングを可能にします。さらに、本パッケージにはTypeScriptのコード構造を解析・ドキュメント化するための高度な解析機能が含まれており、プロジェクト全体における保守性とアーキテクチャの整合性を促進します。

## アーキテクチャ

アーキテクチャは、型安全性、データの整合性、および運用の整合性を維持するために連携する5つの専門モジュールで構成されています。`entity`および`gyomu`モジュールは中核となるドメイン層として機能し、ビジネス固有のエンティティとその対応するCRUDスキーマを定義します。これらのモジュールは、システムサービス、タスクスケジューリング、およびデータ変換全体で整合性を維持するために構造定義に依存しています。

これらのドメインモデルをサポートする`schemas/typescript`モジュールは、静的解析のためのフレームワークを提供し、シンボル、依存関係、およびコードメタデータの体系的な抽出を可能にします。`core`モジュールは共有インフラストラクチャを提供し、結果パターンや、システムレイヤー間での予測可能な通信を保証する低レベルのユーティリティが含まれます。

最後に、`error`モジュールは診断のための一元化された戦略を確立します。動作特性と運用ポリシーを定義することで、システム全体でエラーの分類、コンテキスト、および回復ロジックを標準化します。これらのコンポーネントが組み合わさることで、ドメインロジック、インフラストラクチャ運用、および静的解析が一貫したバリデーションパターンで統合された、堅牢なスキーマ駆動型の環境が構築されます。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/schema
```

## 依存関係

本パッケージはESM環境向けに設計されており、コアランタイムとしてEffect 4.xが必要です。スキーマ定義、コンテキスト管理、およびランタイム操作にはEffectを活用し、日付と時刻のユーティリティには`date-fns`を使用します。これらの依存関係との完全な互換性を維持するために、プロジェクトがESM用に設定されていることを確認してください。

## 開発

Gyomuコアパッケージはプロジェクト全体の基盤層として機能し、ドメイン固有のビジネスエンティティ、サービス定義、および共有ユーティリティ構造の統一されたコントラクトを確立します。コントリビューターは、共有される永続的な、あるいはランタイムで検証されるデータが必ずEffect Schemaを使用して定義されていることを確認し、スキーマのすべてのアノテーションが網羅的であるという要件を厳守する必要があります。これらのアノテーションは、ランタイムバリデーションだけでなく、AI駆動型のワークフロー、ドキュメント生成、コード生成における主要なソースとしても不可欠であるため、オプションのドキュメントではなく重要なメタデータとして扱う必要があります。

アーキテクチャの整合性は、サービスをインターフェースとContext Tagの定義のみに厳格に限定し、実装がこの基盤層から疎結合な状態を維持することで確保されます。ここで提供されるすべてのユーティリティコードは、厳密に純粋である必要があり、アーキテクチャの独立性を維持するために他のGyomuパッケージへの依存を完全に排除する必要があります。本パッケージを発展させる際、コントリビューターは不変かつ宣言的なAPI設計を優先し、共有のBrand型、エラー構造、サービス定義が、プロジェクトの他の部分における標準的な実装リファレンスとして機能する、堅牢で型安全かつ予測可能なインターフェースを提供することを重視してください。

## Public API

- ドメインエンティティモデリング - 構造化スキーマを使用したビジネスエンティティの定義。監査フィールド、UIアノテーション、CRUD操作の自動生成をサポート。
- 構造化エラーハンドリング - 一貫したコンテキスト、動作特性、およびログ記録と再試行のための運用ポリシーを持つ、ドメイン固有のエラーを定義するための堅牢なシステム。
- TypeScript解析フレームワーク - TypeScriptコードの静的解析のための基礎ツール。シンボルマッピング、依存関係追跡、およびJSDocメタデータの抽出を含む。
- 結果およびバリデーションパターン - 操作をラップするための標準化された結果スキーマとユーティリティパターン。レイヤー間の予測可能な通信を保証。
- 運用ライフサイクルサービス - I/O、ネットワーク、およびAIリクエストのシステムライフサイクル管理。再試行戦略、タイムアウト、状態追跡を含む。
- データフォーマットユーティリティ - 日時型、JSONオブジェクト、および文字エンコーディングのための高度な変換および正規化ユーティリティ。
