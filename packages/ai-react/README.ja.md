# Gyomu AI React

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuエコシステム内のReactアプリケーションにAI駆動の機能を統合するための堅牢な基盤を提供します。標準的なユーザーインターフェースとGyomu通信プロトコルの間のブリッジとして機能し、複雑なAIインタラクションのためのシームレスな接続を実現します。

セッション管理、メッセージ変換、状態管理のためのReact特有の抽象化を提供することで、開発者が一貫性と精度を持ってAI機能を組み込めるようにします。また、洗練されたチャットインターフェースの実装を簡素化しつつ、信頼性の高いアプリケーションパフォーマンスを維持するための標準化されたエラー管理機能を提供します。

## アーキテクチャ

@gyomu/ai-reactのアーキテクチャは、UIコンポーネントとGyomu通信プロトコルを接続するように設計されています。複雑なチャットインタラクションを抽象化するステートフルなレイヤーとして機能し、メッセージ変換とステータストラッキングがアプリケーション全体で一貫して行われるようにします。ライフサイクル管理と正規化されたエラーハンドリングのロジックを一元化することで、UIコンポーネントを基盤となるAPIの複雑さから分離します。

このパッケージは、その中核となる操作において厳格な動作契約を維持するように構成されています。内部ロジックは、専用の統合テストおよびユニットテストスイートによって検証されており、リクエスト作成、メッセージマッピング、エラー解析がプロトコル要件に準拠していることを保証します。この検証構造により、ユーザーインターフェースとGyomuバックエンドの間でやり取りされるすべてのデータの整合性が保たれ、ネットワークやAPIとのインタラクション中にも予測可能な結果が得られるようになります。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ai-react
```

## 依存関係

本パッケージはモダンなESM環境を必要とし、React 19およびEffect 4.xと互換性があります。Effectエコシステムに基づいて構築されており、その中核となるアーキテクチャにはEffect SchemaとContextを活用しています。

ランタイム機能は、型定義に@gyomu/schema、ヘッドレスUIコンポーネントに@gyomu/ui-coreを利用しています。さらに、@ai-sdk/reactと統合されており、Reactのライフサイクル内でのAI駆動のインタラクションとストリーム管理を処理します。

## 開発

本パッケージの開発哲学は「予測可能な抽象化」の原則に基づいています。これは、複雑なAIプロトコルのオーケストレーションを直感的なReact Hooks内にカプセル化するものです。私たちは、GyomuベースのアプリケーションへのAI統合において、開発者が状態同期やメッセージ正規化の複雑さを手動で管理する必要があるべきではないと考えています。標準的なReactパターンを反映した宣言的なAPIを提供することで、非同期ストリーミング、セッションの永続化、エラーリカバリといった基盤となる複雑さをUIの実装から分離したままにできます。この構造により、開発者は高品質なユーザー体験の構築に集中し、堅牢な通信プロトコルの負荷を標準化されたインフラストラクチャに委ねることができます。

コントリビューターには「設定よりも構成」の原則に従うことが求められ、洗練されたAIインターフェースを構築するために容易に組み合わせ可能なモジュール式のHooksが優先されます。コード品質は保守性と型安全性によって定義されなければならず、すべての変換と状態遷移は、ミッションクリティカルなGyomuワークフローにおけるランタイム障害を防ぐために厳密に型付けされる必要があります。私たちはエラーハンドリングにおいて防衛的プログラミングを重視し、すべてのネットワークインタラクションが回復力を持ち、ステータストラッキングが有意義で実行可能なフィードバックを提供できるようにしています。コアアーキテクチャを簡潔に保ち、ライフサイクル管理に厳密に集中させることで、APIの進化に対して回復力があり、将来的な拡張性も備えたコードベースを維持しています。

## Public API

- チャットセッション管理 - UIコンポーネント内でチャットセッションを開始、制御、監視するためのReact Hooksを提供します。
- メッセージ正規化 - マルチパートUIメッセージからコンテンツを変換および抽出するためのユーティリティで、一貫したアプリケーションレベルのフォーマットを提供します。
- 回復力のあるAPI通信 - エラー解析を自動化し、バックエンドとの信頼性の高い通信のためにレスポンス例外を処理する設定可能なfetchラッパーです。
- ステータス調整 - 未加工のバックエンドステータス信号を、UIレンダリング用の予測可能な状態インターフェースに標準化します。
