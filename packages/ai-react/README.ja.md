# Gyomu AI React

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステム内のReactアプリケーションにAI機能を統合するための強固な基盤を提供します。AI SDKとプロジェクト固有のトランスポートプロトコルの橋渡し役として、フロントエンド統合の標準化を実現します。

専用のReact Hooksを通じて不可欠な機能を提供することで、チャットセッションの管理、メッセージ変換、状態管理を効率化します。このアーキテクチャは、エラー管理とデータフローの一貫した仕組みを提供することで開発プロセスを簡素化し、AIを活用した機能を信頼性と保守性を備えた形でインターフェースに実装可能にします。

## アーキテクチャ

`@gyomu/ai-react` のアーキテクチャは、AI SDKとGyomu固有のトランスポートプロトコルを接続するモジュール式のブリッジとして構成されています。このパッケージは、セッションのライフサイクル管理と基盤となるデータ変換を分離するように構造化されており、Reactコンポーネントが複雑な通信スキーマを意識せずに済むよう設計されています。機能レイヤーは明確に分割されており、フックがチャットセッションの状態管理と同期を担当し、変換ユーティリティがメッセージ形式の正規化およびマルチパートオブジェクトからのコンテンツ抽出を行います。また、専用のエラーハンドリングレイヤーがネットワークおよびサービス関連の例外を標準化し、アプリケーション全体で一貫したステータス報告を実現します。内部的な整合性は、`src`ディレクトリ内の堅牢なテストインフラによって維持されています。これらのテストは検証レイヤーとして機能し、ライブラリの動作コントラクトを検証することで、パッケージの進化に伴いfetchの作成、メッセージのマッピング、エラー解析の各ロジックが一貫性を保てるようにしています。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/ai-react
```

## 依存関係

本パッケージは、Node.js、React 19、Effect 4.xを中核とするESM環境を前提としています。TypeScriptを活用することで、すべての統合モジュールにおいて堅牢な型安全性を実現しています。

ランタイム機能はシステムアーキテクチャにEffectを採用しており、データ構造やヘッドレスUIコンポーネントには`@gyomu/schema`および`@gyomu/ui-core`を利用します。さらに、`@ai-sdk/react`を統合し、アプリケーション内でのVercel固有のパターンやエラー管理を処理します。

## 開発

本パッケージは、GyomuプロジェクトにおけるAI UI基盤として、ReactアプリケーションとGyomuの通信プロトコルを橋渡しし、一貫したAI機能の統合を実現することを目的としています。開発においては、React Hooksを中心としたAPI設計を徹底し、UI層とGyomu内部プロトコルを厳格に分離することが求められます。コントリビューターは、具体的な実装においてUIコンポーネントが特定のProvider実装に依存しないよう設計し、React以外のフレームワークへの依存を排除することで、ライブラリとしての独立性と保守性を担保しなければなりません。

アーキテクチャの根幹として、メッセージ形式の相互変換を行うレイヤーを介したデータフローの標準化を重視します。チャットセッションのライフサイクル管理や状態遷移は、予測可能性を維持するために一貫したステートモデルに従う必要があり、複雑なデータ抽出やエラーハンドリングも共通化されたメカニズムを適用します。ネットワークやアプリケーションレベルの例外に対しては、標準化されたエラー報告スキームを遵守することで、システム全体の安定性を維持します。今後の開発においては、これらの原則に基づき、UI層の抽象化と内部プロトコルの堅牢な分離を優先した実装を継続してください。

## Public API

- チャットセッション管理 - Gyomuベースのチャットセッションを開始、制御、監視するためのReactフックを提供します。
- メッセージ変換 - AI SDKのプリミティブをアプリケーション固有のスキーマ要件にマッピングすることで、メッセージ形式を標準化します。
- 通信エラーハンドリング - API失敗時に一貫したユーザー体験を保証するため、ネットワークおよびサービスエラーの解析と報告を標準化します。
- メッセージコンテンツユーティリティ - 複雑なマルチパートのチャットメッセージ構造から可読なコンテンツを抽出するヘルパー関数を提供します。
