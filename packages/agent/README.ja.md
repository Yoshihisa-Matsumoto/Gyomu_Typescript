# Gyomu Agent

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステムにおける主要なオーケストレーターとして、インテリジェントエージェントのための堅牢な実行プラットフォームを提供します。高度なAIモデルとプロジェクト固有のコードインテリジェンスを統合することで、洗練された開発ワークフローの作成と管理を実現します。

その中核となる目的は、宣言的かつ拡張可能なエージェント操作を促進し、詳細なコード分析、自動生成、システム更新といったタスクをサポートすることです。スキーマ管理およびドキュメント用の専門的なインフラストラクチャを活用することで、開発者が複雑なソフトウェアエンジニアリングプロセスを合理化する高性能な自動化ツールを構築できるよう支援します。

## アーキテクチャ

@gyomu/agentパッケージは、高度なAI分析とローカルのTypeScriptプロジェクト操作を橋渡しする中央オーケストレーターとして構成されています。自動化エージェントのライフサイクルと状態を管理し、分析目標を具体的なコード関連タスクへ変換するために必要な意思決定ロジックを実装します。

アーキテクチャは、堅牢な検証インフラストラクチャに支えられたコア実行レイヤーを中心に構築されています。`src`ディレクトリ内で、パッケージは品質保証レイヤーとして機能する専門的な検証ツールとテストロジックを保持しています。これらのコンポーネントは、分析操作を厳密な検証にかけることで相互に作用し、プロジェクト入力を処理する際にエージェントが安定性と正確性を維持することを保証します。エージェントのロジックとテストフレームワークを分離することで、自動実行プロセス全体を通じてコア分析ルーチンの信頼性が維持されるようにしています。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/agent
```

## 依存関係

本パッケージは、ESMをサポートするNode.js実行環境を必要とし、Effect 4.x向けに特別に構築されています。現代のTypeScriptプロジェクト内でシームレスに動作するように設計されています。

このライブラリは主要なランタイム基盤として`effect`に依存し、共有型およびスキーマには`@gyomu/schema`を活用します。さらに、コアI/Oおよびインフラストラクチャ操作を処理するために`@gyomu/infra`と統合されています。パッケージの機能を最大限に活用するために、これらの基本依存関係がプロジェクトにインストールされていることを確認してください。

## 開発

本パッケージのアーキテクチャは「Reflective Autonomy（自己反省的な自律性）」という原則に基づいて構築されており、エージェントは単なるテキスト生成器としてではなく、ソフトウェア開発ライフサイクルにおける状態を認識した参加者として機能します。タスク定義に対する宣言的なアプローチを採用することで、高レベルの意図と低レベルの実行を分離し、開発者はコードベースで「何を」達成すべきかを定義し、「どのように」実行するかはモジュール化されたチェーン可能な実行戦略に委ねることができます。この構造により、プロジェクトの複雑さが増してもシステムが保守可能であり続け、コード分析を一連の切断されたプロンプトとしてではなく、永続的で反復的なループとして扱うことができます。

コントリビューターは、プラットフォームを拡張する際に「Composable Observability（構成可能な可観測性）」および「Infrastructure-as-Code-Logic」を優先する必要があります。すべてのエージェントのアクションは追跡可能かつ再現可能である必要があり、AIはローカルのファイルシステムを信頼できる唯一の情報源として尊重し、同期させる必要があります。我々は「Safety-First-by-Design（設計段階からの安全性優先）」の哲学を推奨しており、ヒューリスティックな制約と検証レイヤーがすべてのAI生成操作をラップします。我々の目標は、静的分析から複雑なリファクタリングに至るまでの粒度の細かい機能を、基盤となるTypeScriptプロジェクトの安定性や整合性を犠牲にすることなく、洗練されたワークフローに構成できるエコシステムを育成することです。

## Public API

- エージェントオーケストレーション - 複雑なコード分析や変換タスクを実行可能な自律エージェントを定義・実行するための構造的フレームワークを提供します。
- コードインテリジェンス統合 - 基盤となる構造モデルやドキュメントモデルを利用して、TypeScriptコードの詳細なセマンティック分析を行う機能を提供します。
- 分析ワークフロー管理 - スキーマ検証、AI推論、インフラストラクチャとの相互作用を含む複数ステップのプロセスを調整します。
