# Gyomu AI

[US English](README.md) | JP 日本語

## 概要

本パッケージはGyomuプロジェクトのAI実行基盤として、TypeScriptアプリケーションにおけるAIインタラクションをオーケストレーションするための、モジュール式で復元性の高いフレームワークを提供します。さまざまなプロバイダーやSDK間の差異を抽象化することで、AI統合を標準化することを目的としています。

モデル管理、インテリジェントなリクエストルーティング、および構造化されたツール実行のための統一インターフェースを提供することで、複雑なワークフロー全体で一貫性がありテスト可能な動作を保証します。このアプローチは、エラーハンドリングの集約とシステムフォールバックの自動化によって、信頼性が高くスケーラブルで保守容易なAIアプリケーション開発を促進し、最終的に堅牢なインテリジェンス機能の実装を効率化します。

## アーキテクチャ

本パッケージのアーキテクチャは、モデル管理、リクエストオーケストレーション、ツール実行、エラーハンドリングを分離するモジュール式フレームワークで構成されています。この設計は依存性注入による実行環境を採用しており、Effectサービスを活用することで、すべてのAI操作において堅牢でテスト可能な統合を保証します。

モデル管理層は中央レジストリとして機能し、言語モデルや埋め込みモデルへの構造化されたアクセスを提供します。これらのモデルはルーティング層によって消費され、リクエストフローと自動フォールバック戦略を管理することでシステムの復元性を確保します。ツール実行層は、認可や実行ポリシーを含むAI統合機能に対し、標準化されたインターフェースとライフサイクル契約を確立することでこれを補完します。

これらの操作の基盤として、集中管理されたエラーハンドリングシステムが、ライフサイクルフェーズと運用コンテキストに基づいて障害を分類します。これにより、スタック全体で構造化された診断情報と一貫性のあるメタデータが提供され、モデルの取得からリクエストルーティング、最終的なツール実行に至るまで、明確なトレーサビリティが可能になります。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ai
```

## 依存関係

本パッケージにはESMをサポートするNode.js実行環境が必要であり、Effect 4.xをベースに構築されています。完全な互換性を確保するため、プロジェクトが最新のECMAScriptモジュールおよびEffectエコシステムのパターンを処理できるように設定されていることを確認してください。

コア機能はEffectランタイムに依存しており、共通定義には`@gyomu/schema`、ベースラインのI/O操作には`@gyomu/infra`が利用されます。さらに、AI主導のプロセスに必要な承認ワークフローを提供するため、`@gyomu/approval-core`が統合されています。

## 開発

本パッケージは、GyomuプロジェクトにおけるAI実行基盤として、多様なAIプロバイダーやSDKの差異を透過的に吸収し、統一されたインターフェースを提供することを目的としています。設計の根幹は「抽象化による疎結合」であり、AIモデルへのアクセスは必ず`AiService`および提供される`Provider`を介して行わなければなりません。開発者はプロバイダー固有のSDKを直接利用することを禁じられており、すべてのモデル構成は`Registry`に集約・管理することで、アプリケーション側での直接的な管理を排除し、システム全体の保守性を担保します。

アーキテクチャの信頼性と拡張性を維持するため、すべてのAIリクエストは`Routing`を通じて処理され、単一障害点を防ぐフォールバック構成が強く推奨されます。また、`Effect`サービスを用いた依存注入による実行環境の構築、および構造化されたエラー処理の徹底により、運用時の診断能力を最大化します。Toolの導入に際しては、入力スキーマと実行ポリシーの明示的な定義を義務付け、さらにAIからの出力を信頼せず必要に応じてスキーマ検証を挟むことで、実行環境の安全性と堅牢性を維持することがContributorに求められます。

## Public API

- Model Registry Management - 言語モデルおよび埋め込みモデルの集中的な登録と取得。一貫したモデル設定と注入を可能にします。
- Resilient Request Routing - モデルノードのチェーン定義を可能にする高度なルーティングロジック。実行中にシステムが自動的に代替設定へフェイルオーバーすることを可能にします。
- AI Tooling Framework - ツール定義のための標準化されたアーキテクチャ。スキーマベースの入力バリデーション、実行コンテキスト管理、および承認ポリシーによるセキュリティが含まれます。
- Provider Abstraction - 下位のSDKをラップし、異なるモデルバックエンドやベンダー間で一貫した動作を維持するプラグ可能なプロバイダーアーキテクチャ。
