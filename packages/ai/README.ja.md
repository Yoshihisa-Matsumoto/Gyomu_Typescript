# Gyomu AI

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuプロジェクトにおける基盤となるAI実行レイヤーであり、複雑なAI操作に対して統一されたインターフェースを提供することを目的としています。多様なAIプロバイダーやSDK間の差異を抽象化することで、開発者は信頼性が高く、スケーラブルで保守性の高いアプリケーションを構築できます。

このフレームワークは、TypeScript環境におけるAIインタラクションを調整するためのモジュール化されたアプローチを提供します。モデル管理、自動フォールバックを備えたインテリジェントなリクエストルーティング、および構造化されたツール実行を効率化します。このアーキテクチャにより、AI統合の一貫性とテスト可能性が維持され、高度なAI駆動型ソリューションを開発するための堅牢なインフラストラクチャが提供されます。

## アーキテクチャ

アーキテクチャは、モデル管理、リクエスト調整、およびツール実行を分離するモジュール化されたフレームワークとして構成されています。パッケージの中心には、AIモデルの取得と設定を抽象化するレジストリベースのシステムがあり、依存性注入のための構造化されたサービスレイヤーを提供します。この基盤は、リクエストを特定のモデルにマッピングし、実行の回復力を確保するための自動フォールバックロジックを管理する堅牢なルーティングエンジンを支えています。

本パッケージは、AI統合ツールに対して標準化されたライフサイクルを強制し、定義されたインターフェースと承認ポリシーを利用して実行と権限を管理します。これは、運用上の失敗を分類し、すべてのサービスレイヤーで一貫した診断コンテキストを提供するドメイン固有のエラー管理システムによって補完されます。これらのコンポーネントが組み合わさることで、信頼性の高いテスト可能なAIサービス統合を維持するために、ルーティングレイヤーがモデル、ツール、エラー処理ユーティリティ全体を調整する一貫したパイプラインが形成されます。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ai
```

## 依存関係

本パッケージにはESMをサポートするNode.jsが必要であり、Effect 4.xとシームレスに統合できるように設計されています。インストール前に、プロジェクトの実行環境がモダンなECMAScriptモジュールをサポートするように設定されていることを確認してください。

本パッケージは、その核としてランタイム管理、スキーマ定義、およびコンテキスト処理にEffectエコシステムを採用しています。また、内部の`@gyomu`インフラストラクチャの上に構築されており、共有スキーマ、標準I/Oユーティリティ、および承認プロセスを必要とするAI駆動型ワークフローを管理するための`@gyomu/approval-core`ライブラリを活用しています。

## 開発

Gyomu AIインフラストラクチャは、**型安全な関数型パラダイムを通じたラディカルな抽象化**という原則に基づいて構築されています。LLM APIからカスタムツール実行環境に至るまで、AIプロバイダーをコアのアプリケーションロジックから切り離すべき「不安定な外部副作用」として扱います。Effectエコシステムを活用することで、意図の定義と操作の実行を厳密に分離します。このアーキテクチャ上の選択により、マルチモデルルーティング、ライフサイクル管理、およびプロバイダー固有の癖といった複雑さが完全にカプセル化され、開発者は外部AIサービスの不安定さに左右されず、テスト可能で予測可能、かつ回復力のある機能を構築できます。

本プロジェクトのコントリビューターは、**「利便性よりも均一性」**という哲学を順守する必要があります。新しいモデル統合であれツール定義であれ、あらゆる追加機能は当社の標準化されたインターフェースに準拠しなければならず、これによりシステムがモジュール化され、交換可能であることが保証されます。AI操作は非決定論的であるため、黙示的な実行よりも明示的な失敗状態と堅牢なフォールバックメカニズムを重視し、可観測性と構造化されたエラー処理を最優先事項としています。私たちの目標は、AI特有の複雑さを安全に隠蔽し、Gyomuエコシステム全体の構造的完全性を損なうことなく、エンジニアがプラットフォームを拡張できる、厳格で信頼性の高い基盤を作成することです。

## Public API

- モデルレジストリ管理 - 言語モデルおよび埋め込みモデルの集中的な登録と取得。一貫したモデルの設定と注入を可能にします。
- 回復力のあるリクエストルーティング - モデルノードのチェーン定義を可能にする高度なルーティングロジック。実行中に代替設定へ自動的にフェイルオーバーさせることが可能です。
- AIツールフレームワーク - ツール定義のための標準化されたアーキテクチャ。スキーマベースの入力検証、実行コンテキスト管理、および承認ポリシーを通じたセキュリティが含まれます。
- プロバイダー抽象化 - 低レベルのSDKをラップし、異なるモデルバックエンドやベンダー間で一貫した動作を維持するためのプラグイン可能なプロバイダーアーキテクチャ。
