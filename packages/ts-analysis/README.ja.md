# Gyomu TS Analysis

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステム内のTypeScriptプロジェクトに対して静的解析を行うための堅牢なフレームワークを提供します。開発者はこれを利用して、ワークスペース内のプロジェクト探索のオーケストレーション、ソースファイルの構造化メタデータへの変換、および解析結果の永続化を管理できます。

コード構造、シンボル、依存関係を抽出して統合モデル化することで、プロジェクトのアーキテクチャに一貫した形式でアクセスできるようになります。この永続的で再利用可能なデータは基盤レイヤーとして機能し、AI駆動のサービスやドキュメント生成ツールが複雑なコードベースの情報を信頼性高く解釈・活用することを可能にします。

## アーキテクチャ

本アーキテクチャは、プロジェクトの探索、解析のオーケストレーション、およびユーティリティサポートを分離したモジュール式フレームワークで構成されています。システムは一元化されたエントリーポイントを使用してコアインターフェースを公開しており、これによりコンポーネントはワークスペース管理と静的解析タスクの境界を明確に保ちつつ、効果的に連携できます。

プロジェクトインフラストラクチャは、ワークスペースのスコープを探索・定義し、プロジェクト設定の検証やメタデータの集約を行う専門コンポーネントによって処理されます。このコンテキストは解析エンジンによって利用され、ソースファイルの処理やメタデータのファイルシステムへの永続化が管理されます。このアプローチにより、解析操作が一貫した実行環境で実行されることが保証され、インクリメンタルな処理や効率的なデータ取得が可能になります。

これらのコアエンジンを支えるのが、論理モジュール指定子、ソースファイル、出力成果物間の変換を行うパス解決ユーティリティです。これらの共有コンポーネントはファイルシステムの場所をマッピングするための基礎的なロジックを提供し、複雑なリポジトリ構造全体で解析パイプラインの整合性を維持できるようにします。パスの変換やプロジェクトの探索を解析ロジックから分離することで、本パッケージは静的解析のための安定した拡張性の高い基盤を実現しています。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/ts-analysis
```

## 依存関係

本パッケージはNode.jsを必要とし、Effect 4.xをコアランタイムとして使用するESM環境向けに設計されています。共通定義には`@gyomu/schema`、基盤となるI/O操作には`@gyomu/infra`といった社内インフラパッケージに依存しています。

また、堅牢なTypeScriptコード解析のために`ts-morph`を統合しています。インストール前に、プロジェクトの実行環境がこれらの要件を満たしていることを確認してください。

## 開発

本パッケージは、GyomuにおけるTypeScriptソースコード解析基盤として、プロジェクト全体の構造、シンボル、および依存関係を網羅的に抽出し、再利用可能な構造化データへと変換することを目的としています。この解析基盤は、AI機能やドキュメント生成といった上位レイヤーが直接的に参照する情報源となるよう設計されています。開発者は、ts-morph等の解析ツールに対する直接的な依存を避け、パッケージが提供する抽象化された解析結果モデルを介して情報にアクセスするアーキテクチャを維持してください。設計にあたっては、解析結果がソースコードから導出されるという原則を最優先事項とします。プロジェクト解析とファイル解析の責務を厳格に分離し、解析データはファイルシステムへ永続化することで、差分更新を可能にする増分処理の効率性を担保してください。パス解決やモジュール解決のロジックはWorkspace全体で一貫させつつ、これらの処理とメインの解析処理は疎結合に保つことで、将来的な拡張性や保守性を確保します。貢献者は、解析結果がソースコードに対して読み取り専用であることを守り、TypeScriptプロジェクトの境界を常に明確に管理する方針で開発を進める必要があります。

## Public API

- Project Discovery - TypeScriptプロジェクトおよびワークスペース環境の特定と構造マッピングを可能にします。
- Static Analysis Engine - TypeScriptソースファイルを解析し、シンボルや依存関係情報を抽出するためのコア機能を提供します。
- Persistence Management - 解析結果をディスクにキャッシュおよび保存し、後続の操作のパフォーマンスを向上させます。
- Path Resolution Framework - ソースファイル、出力アーティファクト、モジュール指定子間のパスの正規化、マッピング、変換を行うユーティリティを提供します。
