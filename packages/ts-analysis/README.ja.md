# Gyomu TS Analysis

[US English](README.md) | JP 日本語

## 概要

本パッケージは、TypeScriptプロジェクトにおける静的解析の基盤インフラストラクチャです。ソースコードの構造、シンボル、依存関係を包括的に解析することで、生ファイルをコードベースの内部アーキテクチャを捉えた構造化およびインデックス可能なモデルに変換します。

堅牢なオーケストレーション層として機能するように設計されており、ソースコードと実用的なデータとの橋渡しを行います。プロジェクトコンテキストのライフサイクルを管理し、解析メタデータを永続化して将来の利用に備えます。この構造化された出力は、AI駆動のワークフローや自動ドキュメント生成といった二次的なアプリケーションに対し、信頼できる共通のベースラインを提供し、上位レベルの開発ツール間でのシームレスな統合を実現します。

## アーキテクチャ

パッケージアーキテクチャは、プロジェクト探索と静的解析オーケストレーションを分離する個別のレイヤーで構成されています。システムの核となるプロジェクト管理層は、ワークスペースの境界を識別し、設定を検証し、メタデータを集約します。この基盤インフラストラクチャは、後続のすべての操作のスコープを定義する統一されたプロジェクトコンテキストを確立します。

解析パイプラインはこの基盤の上に構築され、TypeScriptソースファイルを処理して構造化されたメタデータを抽出します。このオーケストレーション層は、実行環境の初期化からインクリメンタル処理のための解析結果の永続化まで、ライフサイクル全体を管理します。多様なファイル構造間で一貫性を保つため、システムは共有パス解決フレームワークに依存しています。このユーティリティ層は、パスの正規化、モジュール指定子のマッピング、ソースファイルとビルド成果物の間の変換を扱い、生コードとインデックス可能なプロジェクトデータの橋渡しをします。環境探索、パス管理、解析オーケストレーションを分離することで、このアーキテクチャはワークスペースを認識する信頼性の高い静的解析のための強力なインターフェースを提供します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/ts-analysis
```

## 依存関係

本パッケージはNode.jsを必要とし、ESM環境向けに設計されています。コアとなるランタイム、スキーマ、依存性注入機能はEffect 4.xに依存しています。

プロジェクトは静的コード解析に`ts-morph`を使用し、共有型やインフラストラクチャロジックの管理には内部の`@gyomu/schema`および`@gyomu/infra`ライブラリを利用しています。インストール前に、プロジェクト環境がこれらのESM依存関係をサポートするように設定されていることを確認してください。

## 開発

本パッケージはGyomuの解析基盤レイヤーとして機能し、複雑なTypeScriptプロジェクト構造をシンボルと依存関係の決定論的で構造化されたモデルに変換する役割を担います。プロジェクト探索、ファイルレベルの処理、パス解決を分離することで、アーキテクチャは解析プロセスがモジュール化され、モノレポ環境の複雑さに対しても弾力性を保つことを確実にしています。コントリビューターは、すべての内部変換がソースコードに対して厳密に読み取り専用のアプローチに従うようにしてください。コードベースを不変の入力として扱い、後続のAIやドキュメントサービスのための信頼できる唯一の情報源として機能する、永続的な構造化成果物を生成します。

解析パイプラインの整合性を維持するため、すべての開発において「解析結果はソースコードから決定論的に導出される」という原則を厳守する必要があります。アーキテクチャはプロジェクトレベルの探索とファイルレベルの処理を明確に分離し、システムがインクリメンタルな更新を実行し、永続化を通じて再利用性を最大化できるようにしています。新機能を実装する際は、モジュール解決ロジックをコア解析ルーチンから分離することを優先し、すべてのパス解決がワークスペース全体で一貫したルールに従うようにしてください。上流の依存関係を本モデルの出力に厳密に限定し、`ts-morph`のような内部ツールへの直接的な依存を防ぐことで、コントリビューターは抽象化レイヤーの安定性を維持し、コードベースの進化に合わせてプラットフォームの保守性を保つことができます。

## Public API

- プロジェクトコンテキスト管理 - 信頼性の高いプロジェクト全体の解析に必要な実行環境の設定、パッケージメタデータ、およびワークスペース設定を初期化・保持します。
- 静的解析パイプライン - TypeScriptソースファイルを処理し、シンボル情報を抽出し、後の取得のために解析結果を保存するための高レベルなオーケストレーションを提供します。
- パス解決フレームワーク - パスの正規化、モジュール指定子の解決、およびソースパスとビルド出力場所のマッピングを行うための堅牢なユーティリティを提供します。
- ワークスペース探索 - リポジトリ全体でTypeScriptプロジェクトを特定・構造化し、ツールが定義されたワークスペース境界内で動作できるようにします。
