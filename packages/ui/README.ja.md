# Gyomu UI

[US English](README.md) | JP 日本語

## 概要

本パッケージは、共有のデザインシステム、スキーマ駆動型のフォーム、および専用のアプリケーションコンポーネントを組み合わせることで、Gyomuのための統合されたユーザーインターフェースを提供します。その目的は、エコシステム全体で一貫性があり、アクセシブルで、保守可能なインターフェースを保証する開発環境を確立することです。

本パッケージは、包括的なコンポーネントライブラリと抽象化レイヤーの両方の役割を果たすことで、UIの実装詳細をコアとなるアプリケーションロジックから効果的に分離します。このアーキテクチャにより、再利用性と拡張性に優れたインターフェース要素の作成が促進され、厳格なデザイン基準とMaterial UIとの高品質な統合を維持しながら、スケーラブルなアプリケーション構築を効率化します。

## アーキテクチャ

@gyomu/uiのアーキテクチャは、アトミックなUIビルディングブロックと、高レベルなフォームオーケストレーションおよびサードパーティ製フレームワークの統合を分離するモジュール構造で構成されています。基盤となるインターフェース要素とヘッドレスなレイアウトコンポーネントが構造的なベースを提供し、共有プロバイダーコンテキストがライブラリ全体の相互作用パターンとグローバルな状態を管理します。

システムは抽象化レイヤーを利用してMaterial UIの依存関係をカプセル化し、フォーム入力の一貫したスタイルと特殊な動作を保証します。このアダプター層はフィールドインターフェースを標準化し、検証戦略やレイアウトのデフォルト値といったプロジェクト固有の設定を、ベースとなるフレームワークコンポーネントに注入します。

最後に、宣言的なフォーム生成システムがデータスキーマを消費することで、インターフェース構築を自動化します。このコンポーネントは動的なフィールドレンダリングを管理し、送信制御のための外部ハンドルを提供します。スキーマ駆動型のオーケストレーションを基盤となるUIアダプターやレイアウトプリミティブと連携させることで、アプリケーション全体で統一されたインタラクションパターンを維持しつつ、フォーム生成と特定の視覚的実装との分離を保証します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ui
```

## 依存関係

本パッケージはESM環境を必要とし、React 19およびEffect 4.xと互換性があります。ランタイムロジックとスキーマ管理にはEffectエコシステムに基づいて構築されており、共有の型定義には@gyomu/schemaを活用しています。

UIレイヤーは、一貫したデザインシステムを提供するためにMaterial UIおよびshadcn/uiコンポーネントに依存しています。インストール前に、プロジェクトがこれらの依存関係をサポートするように設定されていることを確認してください。

## 開発

本パッケージは、Gyomuにおける統一されたユーザーインターフェース基盤として、保守性・一貫性・アクセシビリティを最大化することを目的としています。デザインシステムと共通コンポーネントを軸に、UIフレームワークの実装詳細をアダプター層へ分離することで、特定のライブラリに依存しない再利用可能かつ拡張性の高いUIライブラリを実現します。これにより、アプリケーションロジックとUI表現を明確に切り離し、将来的なフレームワークの更新や仕様変更にも柔軟に対応可能なアーキテクチャを維持します。

開発においては、フォームやレイアウトの定義においてUI記述の重複を排除し、スキーマ駆動のアプローチを徹底してください。すべてのコンポーネントは合成可能な単位で設計し、型安全性と予測可能性を重視して実装する必要があります。また、共有Providerを活用した状態管理や、アクセシビリティ標準の遵守を必須とし、レイアウト構造と視覚表現を分離した設計を維持することで、画面全体を通じて一貫性のあるユーザー体験を担保してください。

## Public API

- Design System Components - アバター、カード、ボタン、入力フィールドなどのアトミックおよび複合UI要素のライブラリを提供します。
- Declarative Form Automation - データスキーマからのフォーム自動構築を可能にし、レイアウトのオーケストレーションと送信処理を組み込みで提供します。
- Material UI Integration - Material UI用の標準化されたラッパーとレイアウトアダプターを提供し、一貫したスタイリングと機能的動作を保証します。
- Headless Form Layouts - 固定的な視覚スタイルを強制することなく、フォームおよびフィールドのレイアウトを定義するための構造的コンポーネントを提供します。
- Global Interaction Management - ツールチップやトースト通知など、アプリケーション全体のUI状態を一元管理します。
