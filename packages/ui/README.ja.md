# Gyomu UI

[US English](README.md) | JP 日本語

## 概要

本パッケージは、共有のデザインシステム、スキーマ駆動型のフォーム、および特化したアプリケーションコンポーネントを組み合わせることで、Gyomuのための統合されたユーザーインターフェースを提供します。その主な目的は、長期的な保守性、視覚的な一貫性、およびアクセシビリティを優先するインターフェースを開発者が構築できる環境を促進することです。

このライブラリは包括的な抽象化レイヤーとして機能し、UIの実装詳細とコアとなるアプリケーションロジックを分離します。このアーキテクチャにより、再利用性が高く拡張性に優れたインターフェースの作成が可能になります。また、低レベルのビルディングブロックと宣言的な生成システム、および専用のMaterial UIアダプターを統合することで、エコシステム全体で一貫した開発体験を保証します。

## アーキテクチャ

アーキテクチャは、基本的なUIプリミティブ、レイアウト構造、および高レベルな宣言的フォームシステムを分離するモジュール化された階層構造で構成されています。コアとなるUIコンポーネントは、原子的なビルディングブロックと複合的な要素を提供し、アプリケーション全体で一貫したインタラクションパターンと視覚テーマを保証します。これらのコンポーネントは、共有のContextおよびProviderラッパーを通じて統合され、統一された状態管理を維持します。

本パッケージは、特にMaterial UIを統合するためのアダプターコンポーネントを通じて抽象化レイヤーを活用しています。これらのアダプターはサードパーティの依存関係をカプセル化し、プロジェクト固有のスタイリング、バリデーションロジック、および標準化されたプロパティインターフェースをベースフレームワークの要素に注入します。

最上位レベルでは、宣言的なフォームシステムがインターフェース構築を自動化します。スキーマ定義を活用することで、特定の視覚スタイルを強制しないヘッドレスレイアウトコンポーネントを使用し、動的なフィールドのレンダリングを調整します。このような関心の分離により、フォームエンジンは複雑なレイアウトロジックや外部の送信制御を管理しつつ、具体的な視覚的実装から分離された状態を維持できます。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ui
```

## 依存関係

本パッケージはReact 19を必要とし、Effectバージョン4.xを基盤として構築されています。これらのバージョンをサポートするモダンなTypeScript環境でシームレスに動作するように設計されています。

プロジェクトの核として、ランタイムとスキーマ管理にEffectを活用し、共有型として`@gyomu/schema`を使用します。ユーザーインターフェースに関しては、Material UIとshadcn/uiコンポーネントを統合し、一貫性のあるレスポンシブなデザインシステムを提供します。インストール前に、実行環境がこれらのバージョン要件を満たしていることを確認してください。

## 開発

このパッケージは、GyomuにおけるUI開発の標準化と効率化を目的としており、共通デザインシステムとコンポーネントライブラリを中核に据えています。開発においては、UIコンポーネントの再利用性と合成可能性を最優先し、特定の画面構成に依存しない疎結合な設計を徹底してください。また、フォーム開発ではスキーマ駆動のアプローチを採用し、データ構造からUIを動的に導出することで、定義の重複を排除し、保守性と型安全性を担保することを原則とします。

アーキテクチャの維持にあたっては、UIフレームワーク固有の実装をアダプター層へ分離し、ロジックと視覚表現の関心事を明確に分ける必要があります。レイアウト構造と視覚表現を独立させることで、システム全体の拡張性を確保してください。すべてのコンポーネントはアクセシビリティと予測可能性を重視し、共有Providerを介してアプリケーション共通のUI状態を管理することで、一貫性のあるユーザーインターフェースを維持・発展させていくことが求められます。

## Public API

- デザインシステムコンポーネント - アバター、カード、ボタン、入力フィールドなどの、原子的なUI要素や複合的なUI要素のライブラリを提供します。
- 宣言的フォーム自動化 - データスキーマからのフォームの自動構築を可能にし、レイアウトの調整と送信処理を組み込みます。
- Material UI統合 - Material UI用の標準化されたラッパーとレイアウトアダプターを提供し、一貫したスタイリングと機能的動作を保証します。
- ヘッドレスフォームレイアウト - 固定された視覚スタイルを強制することなく、フォームやフィールドのレイアウトを定義するための構造コンポーネントを提供します。
- グローバルインタラクション管理 - ツールチップやトースト通知など、アプリケーション全体のUI状態管理を一元化します。
