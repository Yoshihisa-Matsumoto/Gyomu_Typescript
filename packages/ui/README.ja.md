# Gyomu UI

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuの統一されたユーザーインターフェース環境を提供する、主要なデザインシステムおよびコンポーネントライブラリです。基本的なビルディングブロック、宣言的なフォーム生成、およびアーキテクチャ上のアダプターを統合し、アプリケーション全体で視覚的および機能的な一貫性を確保します。

UIの実装詳細とアプリケーションロジックを分離することで、本ライブラリは保守性と拡張性を重視したモジュール型アーキテクチャを促進します。このアプローチにより、開発者は標準化されたコンポーネントの挙動とレイアウトを適用しながら、アクセシブルで再利用可能なインターフェースを構築でき、プロジェクトエコシステム全体で高品質かつプロフェッショナルなユーザー体験の作成を効率化します。

## アーキテクチャ

本パッケージのアーキテクチャは、基盤となるUIライブラリ、サードパーティ統合用のアブストラクション層、宣言的なフォーム生成エンジンの3つの主要なレイヤーで構成されています。UIライブラリはアトミックおよびコンポジットなビルディングブロックを提供し、アブストラクション層はブリッジとして機能し、Material UIコンポーネントをラップすることでプロジェクト固有のテーマ、スタイリング、および動作制約を強制します。

宣言的なフォームシステムは、これらのコンポーネントを統括し、スキーマ定義を利用してフィールドのレンダリングとレイアウトを自動化します。懸念事項を分離することで、本アーキテクチャは構造的なレイアウトロジックを特定のコンポーネントスタイルから分離した状態に保ちます。ヘッドレスなレイアウトコンポーネントがフォームフィールドとコンテナの配置を管理することで、柔軟な構成を可能にします。

最終的に、本パッケージは高レベルのフォームがスキーマ駆動のロジックを利用して適応型のフィールドコンポーネントをインスタンス化する、共同的な階層構造によって機能します。この設計はタイポグラフィとスタイリングの設定を一元化し、アダプター層内にサードパーティの依存関係を隔離しつつ、アプリケーションインターフェース全体で一貫性を確保します。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/ui
```

## 依存関係

本パッケージはNode.jsを必要とし、React 19およびEffect 4.xとの互換性を備えています。Effect Runtime、Schema、Contextを含むEffectエコシステムを活用し、アプリケーションロジックのための堅牢な基盤を提供します。ユーザーインターフェースにはMaterial UIおよびshadcn/uiのコンポーネントを統合しています。さらに、共有の型やスキーマの集約元として`@gyomu/schema`を利用し、プロジェクト全体でデータ構造の一貫性を確保します。

## 開発

Gyomu UIライブラリは、アプリケーションの保守性、一貫性、そしてアクセシビリティを最大化するための基盤として設計されています。その中核には、UIフレームワーク固有の実装をアダプター層へ分離し、ロジックと視覚表現を完全に切り離すという設計指針があります。これにより、特定の外部ライブラリへの過度な依存を防ぎ、将来的な技術選定の変更や機能拡張に対して、UIコンポーネントが常に高い独立性と再利用性を維持できる構造を目指します。開発者は、コンポーネントの設計において「合成可能であること」と「型安全であること」を最優先してください。フォーム実装に関しては、ハードコードを避け、スキーマから導出される宣言的なインターフェースを介することで、重複を排除し、一貫したレイアウトパターンを担保します。UIの振る舞いやスタイルといった共通設定は中央管理し、アプリケーション固有のロジックとデザインシステムが衝突しない環境を維持してください。予測可能性とアクセシビリティを備えた標準化されたインターフェースを提供することが、本ライブラリにおける持続的な進化の鍵となります。

## Public API

- Design System Components - プロジェクト全体のスタイリングとインタラクションパターンを強制する、プリミティブおよびコンポジットUI要素の包括的なスイート。
- Declarative Form Generation - 提供されたスキーマに基づいてフォーム全体をレンダリングする自動化システム。複雑なデータ入力における手動のボイラープレートを削減します。
- Component Adaptation - Material UIなどのサードパーティライブラリを統合し、プロジェクト固有の要件やテーマ制約に準拠させるための標準化されたラッパー。
- Form Layout Management - フォームフィールド、ラベル、エラー状態の配置を一貫した構造にするための、ヘッドレスおよびスタイル付きのレイアウトコンポーネント。
- UI Utility Integration - Tailwind CSSクラスの結合を一貫して行うための、クラス名の合成および条件付きスタイリング用の共有ユーティリティ関数。
