# Gyomu AI Compiler

[US English](README.md) | JP 日本語

## 概要

本パッケージは、GyomuプロジェクトのAIコードインテリジェンスの基盤として機能します。宣言的パイプラインの構築と実行を可能にすることで、コード分析やドキュメント生成といった複雑な開発タスクを自動化するための構造化されたフレームワークを提供します。

標準化されたスキーマと一貫した実行戦略を利用することで、JSDocの更新、リポジトリの要約、ドキュメントコンポーネントなどのAI駆動によるメンテナンスが、検証可能かつ高い保守性を維持することを保証します。このアプローチは再現性と技術的な厳密さを優先しており、最終的にコードベース全体を通じた、より信頼性の高いAI支援開発を促進します。

## アーキテクチャ

このアーキテクチャは、データモデリング、戦略的意思決定、実行を分離するモジュール式パイプラインを中心に構成されています。ドキュメントコンテキストの定義と生成ロジックを分離することで、コードメンテナンスに対して一貫性があり検証可能なアプローチを保証します。この責務の分離により、システムはコードの複雑性を個別に評価し、構造化されたドキュメントの更新を計画し、変更を実行することができます。

組織的には、パッケージはJSDoc更新やファイル要約などのタスク固有のモジュールに分割されています。各モジュールは内部コンポーネントを活用して自身のライフサイクルを管理します。コンテキストハンドラが必要なメタデータとスキーマを定義し、Resolverが適切な分析深度を決定し、Executorが最終的な生成および統合タスクを実行します。これらのコンポーネントは、ソースコード構造を表現するスキーマベースのモデルを介して連携し、AIによる出力が既存のコードベースと整合性を保ちつつ、推論結果と安全性評価を付与することで監査可能性を維持します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ai-compiler
```

## 依存関係

本パッケージはESMをサポートするNode.js環境を必要とし、Effect v4を基盤として構築されています。ライブラリの型安全およびスキーマ定義を最大限に活用するために、TypeScriptの使用を推奨します。

実行時には、コアランタイムとコンテキスト管理のためにEffectエコシステムに依存しています。また、内部インフラストラクチャおよびAIモジュール（@gyomu/schema、@gyomu/infra、@gyomu/ai）とシームレスに統合されており、必要な共通型、I/O処理、およびLLM処理機能を提供します。

## 開発

このパッケージのアーキテクチャは、コードインテリジェンスを不透明なプロンプトベースのプロセスではなく、構造化された決定論的なパイプラインとして扱う「意図的なオーケストレーション（Intentional Orchestration）」の原則に基づいています。ソースコードとドキュメント状態に対してスキーマベースのモデルを強制することで曖昧さを排除し、AIが厳格で明確に定義されたコンテキスト内で動作することを保証します。この構造は、タスクの「何」と「なぜ」という高レベルの意図を、「どのように」実行するかという低レベルの処理から分離するように設計されており、多様なAIモデル構成の複雑さを抽象化しながら、変更管理を厳密に制御することを可能にしています。

貢献者は、「宣言的再現性（Declarative Reproducibility）」の哲学に従う必要があります。すべての変換は追跡可能で、再現可能で、個別にテスト可能であるべきです。目標は、不安定でモノリシックな対話から、安全性と一貫性を優先した、細粒度で戦略主導型のワークフローへと移行することです。貢献者には、タスク計画のロジックとコード変更のメカニズムを明確に分離すること、プロンプトの巧妙さよりもスキーマの堅牢性を優先すること、そして既存パイプラインの整合性を損なうことなく新しいインテリジェンスモジュールを統合できる拡張性を維持することが求められます。

## Public API

- JSDocドキュメントライフサイクル - コードシンボルの分析、JSDoc更新の計画、および生成されたドキュメントと既存コメントの調整を管理するための包括的なツール群。
- コードベースの要約 - 個々のシンボルの要約から、ファイルレベルの概念、ディレクトリ全体のアーキテクチャ概要に至るまで、階層的にインサイトを抽出します。
- パイプライン実行フレームワーク - 特定のタスク入力をAIモデルのルートに接続し、複雑性の評価とタスク設定を処理する堅牢なオーケストレーション層。
- プロジェクトドキュメント自動化 - 現在のコードベースの状態に基づいて、READMEセクションなどのプロジェクトレベルのドキュメントを動的に生成および更新するための機能。
