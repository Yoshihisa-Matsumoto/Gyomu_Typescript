# Gyomu AI Compiler

[US English](README.md) | JP 日本語

## 概要

本パッケージは、GyomuプロジェクトにおけるAIコードインテリジェンスの基盤として機能します。ソースコード解析、ドキュメント生成、コード要約といった複雑なタスクを自動化するための構造化されたフレームワークを提供します。これらのプロセスを宣言的なパイプラインとして形式化することで、AI主導の開発における一貫性、再現性、および高い保守性を維持します。

本プラットフォームは、定義済みのスキーマと実行パイプラインを利用し、ソースコードのメタデータをプロジェクトレベルの要約やドキュメント計画などの実用的なインサイトへと変換します。入力コンテキストと出力設定を標準化することで、TypeScriptコードベースに対して確定的で監査可能な変換を実現します。このアプローチにより、技術的な正確性とプロジェクトガバナンスの高い基準を維持しつつ、AI支援ワークフローを効率化します。

## アーキテクチャ

本アーキテクチャは、コード解析とドキュメント作成を自動化する専用のパイプラインを中心に構成されています。これらのパイプラインは、データコンテキスト、スキーマ定義、実行ロジックを担当するレイヤーに機能的に分割されています。ソースコードメタデータの表現と操作ロジックを分離することで、JSDocの更新やファイル要約といったドキュメント作成タスクにおいて、確定的かつ監査可能な状態を保証します。

コンテキストレイヤーは、ソースコードのシンボルやファイルレベルのConceptがどのように表現されるかを標準化し、後続の解析に対して一貫した基盤を提供します。スキーマレイヤーは変換計画の構造を定義し、追加や削除といった意図した変更だけでなく、監査に必要な根拠や安全性の評価もカプセル化します。最後に、実行およびモードレイヤーがパイプラインのフローを制御します。ここでは複雑性戦略を用いて適切な更新モードを解決し、変換処理の適用をオーケストレートします。このモジュール式アプローチにより、各コンポーネント間の構造化されたデータ駆動型の連携を通じて、TypeScriptプロジェクト全体で一貫したドキュメント標準を維持します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ai-compiler
```

## 依存関係

本パッケージにはESMをサポートするNode.js実行環境が必要であり、Effect v4をベースに構築されています。すべての統合モジュールにおいて型安全性を確保するためにTypeScriptを使用しています。

本プロジェクトは、ランタイムおよびスキーマ管理のためにEffectエコシステムの中核機能に依存しています。さらに、`@gyomu/schema`、`@gyomu/infra`、`@gyomu/ai`と統合されており、それぞれ共通のデータ構造、インフラストラクチャユーティリティ、およびLLM処理機能を提供します。実装の前に、これらの依存関係がワークスペース内で正しく設定されていることを確認してください。

## 開発

本パッケージはGyomuプロジェクトの中核となるAIコードインテリジェンスエンジンであり、一貫性があり、再現可能で保守性の高いAI支援開発を促進するように設計されています。これを実現するため、アーキテクチャは関心の厳格な分離を強制します。すべてのAIタスクは独立したパイプラインとして構成され、入力と出力は標準化されたスキーマによって管理されます。これらのスキーマを正式な規約として扱うことで、すべての自動化された操作において型安全性を確保し、コントリビューターがシステムの不安定性を招くことなく、より広範なメンテナンスワークフローに確実に統合できるモジュール型コンポーネントを構築できるようにします。

本コードベースの発展は、解析フェーズと計画フェーズの厳密な分離に依存しており、AIによって生成されたインサイトが提案されたコード修正とは明確に区別されることを保証します。すべての変換は実行前にPlanを通じて検証される必要があり、監査可能性と安全性を担保する確定的メカニズムを提供します。コントリビューターは、すべてのAIタスクを定義されたRoutes経由でルーティングすることが求められます。これにより、モデルの設定と特定の処理ロジックの間に明確な境界が維持されます。複雑性や更新モードがこれらの構造化されたパイプラインを通じて処理されることで、あらゆる自動化された変更の整合性と追跡可能性を維持しつつ、多様なコード規模に適応可能なアーキテクチャが保たれます。

## Public API

- JSDoc自動化 - シンボルの複雑性や構造メタデータに基づき、JSDocコメントの解析と自動更新をオーケストレートします。
- コードベース要約 - ファイル、ディレクトリ、パッケージ全体の簡潔な概念的要約を生成し、開発者のナビゲーションやドキュメント作成を改善します。
- パイプラインオーケストレーション - 設定可能なコンテキストと戦略を用いて、さまざまなAI駆動のコード解析タスクを実行するための、一貫した実行フレームワークを提供します。
- コンテンツ翻訳 - 設定されたAIモデルのRouteを使用して、技術ドキュメントや要約を翻訳するためのインフラストラクチャを公開します。
- README生成 - 構造化されたAI駆動型テンプレートを使用し、READMEファイル内のドキュメントセクションをプログラムで構築することをサポートします。
