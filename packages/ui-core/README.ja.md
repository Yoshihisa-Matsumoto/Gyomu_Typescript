# Gyomu UI Core

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステム内で一貫したユーザーインターフェースを構築するための強固な基盤を提供します。生のデータスキーマとインタラクティブなコンポーネントとの間を橋渡しすることで、フォームや複雑なUI構造の自動生成を可能にします。

本フレームワークは、入力バリデーション、エラー管理、レンダリングロジックを統合されたモデルに集約します。このアプローチにより、UIの実装とデータモデリングを効果的に分離し、プラットフォーム全体でアプリケーションの型安全性、保守性、および視覚的な一貫性を維持します。

## アーキテクチャ

@gyomu/ui-coreのアーキテクチャは、データスキーマとインタラクティブなUIコンポーネントを橋渡しするモジュール式システムで構成されています。その中核には、構造的なスキーマをフォームメタデータに変換するDSL層があり、ライブラリ全体の基礎となる設定として機能します。

このメタデータはフォームエンジンによって処理され、フォーム構造の生成を調整します。エンジンは、デフォルト値の初期化、ウィジェットタイプのマッピング、定義された制約に基づくユーザー入力の検証といったライフサイクル管理を担います。これにより、フォームのレンダリングとデータ整合性に対する一貫したアプローチを保証します。

これらの操作をサポートするのは、中央集権的なエラー管理システムです。このインフラストラクチャはUI関連のエラーを分類し、標準化された回復戦略を実行することで、バリデーションや処理の失敗を扱うための統合されたメカニズムを提供します。ルートオーケストレーション層はこれらのコンポーネントを統合し、コンシューマーが動的なフォームを定義、レンダリング、管理しつつ、アプリケーション全体で一貫したエラーハンドリングを維持できるような、まとまりのあるインターフェースを公開します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/ui-core
```

## 依存関係

本パッケージはESM環境向けに設計されており、React 19およびEffect 4.xと互換性のあるNode.jsを必要とします。Effectエコシステム（Effect SchemaやContextを含む）の上に構築された軽量な統合層として機能し、型安全なランタイム操作を提供します。

主要機能は、コアランタイムについては`effect`ライブラリに、共有定義や共通型については`@gyomu/schema`に依存しています。インストール前に、プロジェクトの実行環境がこれらのESMベースの依存関係をサポートするように設定されていることを確認してください。

## 開発

本パッケージは、GyomuにおけるUIの共通基盤として、データスキーマからフォームやUI構造を自動的に導出する仕組みを提供することを目的とします。設計の根幹には「UIはスキーマから導出可能な構造である」という原則があり、データモデルとUI実装を厳密に分離することで、システム全体での型安全性を担保します。貢献者は、UI定義をデータモデルとは独立したDSLとして管理し、レンダリング処理とUI定義を疎結合に保つ必要があります。これにより、UIの変更がデータ構造に不要な影響を与えない柔軟なアーキテクチャを実現します。

開発においては、入力検証の唯一の基準をデータスキーマに定め、個別のコンポーネントに検証ロジックを分散させない方針を徹底してください。エラー処理については、コンポーネントへの直接実装を禁止し、共通モデルに基づいた一元的なハンドラーを利用することを必須とします。Reactコンポーネントの役割は、あくまで提供されたUIモデルを忠実に描画することに限定し、ロジックの分離を維持してください。これらの設計原則を守ることで、大規模なフォームや複雑なUI構造であっても、Gyomu全体で一貫した振る舞いと堅牢なエラー管理を維持することが可能です。

## Public API

- フォームの自動生成 - 構造的なスキーマ定義から直接、フォーム構造やフィールドメタデータを動的に生成します。
- スキーマ主導のバリデーション - CRUD準拠のスキーマに対し、フィールド入力やフォーム全体の状態をバリデーションする仕組みを提供します。
- UIエラーのオーケストレーション - UIエラーの分類、設定、処理方法を標準化し、リトライロジックやユーザーへのフィードバックをサポートします。
- コンポーネントレンダリングフレームワーク - ウィジェットの設定を特定のReactコンポーネントにマッピングし、一貫したレンダリングとインタラクションの処理を可能にします。
