# Gyomu UI Core

[US English](README.md) | JP 日本語

## 概要

本パッケージは、GyomuエコシステムにおけるUI開発のための統合基盤を提供します。データスキーマからフォームや構造コンポーネントを直接導出することで、入力バリデーション、エラーハンドリング、レンダリング設定を単一の cohesive なモデルに集約します。

本フレームワークは、UI実装と基盤となるデータ構造の分離を促進します。このアプローチにより、型安全で一貫性のあるインターフェースを確保しつつ、フォーム生成の自動化とエラー管理の標準化を実現します。ドメインスキーマを活用してUIメタデータを制御することで、アプリケーション全体を通じて堅牢でスケーラブルなユーザー体験を維持することが可能になります。

## アーキテクチャ

本アーキテクチャは、ドメイン固有の変換、自動フォーム生成、堅牢なエラー管理を統合する集中型のオーケストレーション層で構成されています。このパッケージは、その中心部でドメイン固有言語 (DSL) 層を利用し、生のデータスキーマとUI向けのメタデータを橋渡しすることで、構造定義がフォーム設定へ一貫して変換されるようにしています。

フォーム生成エンジンはプライマリサービスとして機能し、このメタデータを活用して状態の初期化、フィールドタイプからリアクティブなウィジェットへのマッピング、およびスキーマに基づくバリデーションの実行を行います。このエンジンはエラーハンドリングシステムと密接に連携しており、エラーの分類と復旧ワークフローの実行を行うための標準化されたフレームワークを提供します。DSL変換ロジックを操作エンジンおよびエラー管理インフラストラクチャから分離することで、本パッケージはモジュール式の構造を維持し、アプリケーション全体でデータ整合性と一貫したユーザーフィードバックを確保しています。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/ui-core
```

## 依存関係

本パッケージは、ESMをサポートするNode.js実行環境を必要とし、Effect 4.xおよびReact 19.xでの使用を前提として設計されています。現代的なWebアプリケーションのための型安全な基盤として機能し、最新のReactおよびEffectエコシステムとの完全な互換性を確保します。ランタイムにおいて、本プロジェクトは中核となるランタイム、スキーマバリデーション、およびコンテキスト管理のためにEffectライブラリに依存しています。さらに、@gyomu/schemaと統合することで、アプリケーション全体で共有される型定義と標準化されたデータスキーマを提供します。

## 開発

本パッケージは、GyomuにおけるUI開発の共通基盤として、データスキーマからフォームおよびUI構造を導出する仕組みを提供します。その核心は、UI実装とデータモデルを分離し、型安全かつ一貫性のあるインターフェースを実現することにあります。貢献者は、UIをスキーマから導出可能な構造として定義し、フォーム定義とデータモデルの不整合を排除する設計を徹底してください。UIメタデータはデータモデルとは独立したDSLとして管理し、レンダリング処理とUI定義を疎結合に保つことで、変更に強く再利用性の高い構成を維持することが求められます。入力検証およびエラー処理については、スキーマを唯一の基準として一元管理することを基本方針とします。個別のコンポーネントにロジックを直接実装することは避け、共通のエラーハンドラーとモデルを介してエラーの分類および回復ワークフローを制御してください。Reactコンポーネントは、受け取ったUIモデルをレンダリングする責務のみを負うものとし、ビジネスロジックや検証ルールを内部に持たせないことが重要です。今後、新たなウィジェットやマッピングを追加する際は、これらのポリシーを遵守し、宣言的なUI定義と自動化された状態初期化の原則を逸脱しないようにしてください。

## Public API

- フォームの自動生成 - 構造的なデータスキーマから直接、UIフォームの設定と初期データ状態を構築します。
- スキーマ駆動型のバリデーション - 定義済みのCRUDスキーマ制約に基づいてユーザー入力を検証し、フォーム内のデータの整合性を維持します。
- UIエラー管理 - UI関連のエラーを分類、表示、処理するための一貫したメカニズムを提供し、カスタムリトライ動作をサポートします。
- コンポーネントレンダリング基盤 - 一元化されたレンダラーレジストリを介して、カスタムReactコンポーネントをフォームのフィールド型に関連付け、登録できるようにします。
