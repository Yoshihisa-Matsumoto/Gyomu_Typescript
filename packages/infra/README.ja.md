# Gyomu Infra

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステムの基盤となるインフラストラクチャ層であり、Effect上に構築された一貫性のあるサービス指向アーキテクチャを提供します。その主な目的は、ファイルシステム管理、データベース操作、ネットワーク通信、データシリアライズといった一般的な運用タスクを、信頼性の高い型安全なサービスとして抽象化することです。

これらの横断的な関心事を集約することで、アプリケーションロジックをプラットフォーム固有の実装や外部ライブラリから分離します。このアーキテクチャにより、実行環境の安定性と一貫性が保たれ、開発者はエコシステム内のあらゆるコンポーネント間で型安全性と運用上の整合性が維持された共通インターフェースを利用できます。

## アーキテクチャ

アーキテクチャは、Effectエコシステム上に構築されたモジュール式のサービス指向層として構成されています。ファイルシステム操作、データベース接続、ネットワーク通信、データシリアライズのための専門モジュールを提供することで、横断的な関心事を集約します。この構造により、アプリケーションエコシステム全体で一貫したエラーハンドリングと型安全な統合が保証されます。

本パッケージは、責務をファイル管理、データベースリポジトリパターン、Webサービス統合、データ解析という明確な機能ドメインに分割しています。各モジュールは、高レベルなビジネスロジックを基盤となるプラットフォームの実装から分離するサービス層の抽象化を通じて動作します。例えば、データベース層はリポジトリの抽象化を通じて接続のライフサイクルを管理し、WebおよびファイルモジュールはI/Oやストリーム処理のための標準化されたインターフェースを提供します。

連携するコンポーネントは双方向のデータ変換を容易にし、構造化されたドメインモデルとCSV、XML、JSONといった外部フォーマット間のシームレスな変換を可能にします。共有の設定とユーティリティプロバイダーを活用することで、これらのコンポーネントはアーキテクチャの一貫性を維持し、インフラストラクチャ層が複雑なサービス間のやり取りやデータ駆動型の操作における信頼できる基盤として機能します。

## インストール

pnpmを使用してインストールしてください。

```bash
pnpm add @gyomu/infra
```

## 依存関係

本パッケージはNode.jsを必要とし、Effect 4.xをコアランタイムおよびスキーマの基盤として活用するESM環境向けに設計されています。共有の型定義およびデータ検証には `@gyomu/schema` を使用します。

SSH、FTP、Zip操作用の統合モジュールが含まれていますが、これらは必要な場合にのみ読み込まれるようエクスポートパスを介して実装されています。これにより、プロジェクトのニーズに合わせてランタイムのフットプリントを軽量に保つことができます。

## 開発

本パッケージは、Gyomuエコシステムにおける共通インフラストラクチャ基盤として、アプリケーションロジックをプラットフォーム固有の制約から解放することを目的としています。設計の核心は、ファイル操作、ネットワーク通信、データベース接続といった副作用をEffectベースのサービスとして厳格に抽象化することにあります。貢献者は、外部ライブラリや環境依存の実装を直接アプリケーション層に混入させるのではなく、必ず定義されたサービスインターフェースの背後に隠蔽しなければなりません。これにより、インフラ層の差し替えがアプリケーションロジックに影響を与えない、疎結合でテスト容易性の高い実行環境を維持します。

実装においては、型安全性を最優先事項としたエラーハンドリングとデータ整合性の保証が求められます。すべての外部操作は共通のエラーモデルに基づいて分類し、診断可能な情報を保持する形で実装してください。また、データ変換や外部I/Oの境界では、スキーマ検証を通じてドメインモデルとの整合性を保証し、大量データ処理においてはストリームベースのアプローチを優先的に採用することで、スケーラビリティとリソース効率を両立させます。すべてのインフラ機能は特定業務への依存を排除し、汎用的なコンポーネントとして設計・保守することで、エコシステム全体での一貫性と再利用性を担保してください。

## Public API

- ファイルシステム操作 - ローカルファイルの操作、ストリーミング、検索、メタデータ管理のための包括的なユーティリティ。エラーハンドリングが統合されています。
- データベース統合 - KyselyおよびMSSQL向けの抽象化された接続機能とリポジトリパターン。型安全なCRUD操作とカスタムクエリの実行を可能にします。
- Webおよびネットワークアクセス - HTTPリクエストの実行、リモートコンテンツのダウンロード、ネットワークストリーム応答の処理機能。
- データシリアライズ - CSV、JSON、XML、YAML間の双方向変換ユーティリティ。データ整合性を確保するため、スキーマ検証と統合して利用されることが多いです。
- DOMおよびスクレイピング - HTMLコンテンツの解析、ナビゲーション、クエリ実行のための抽象化。ドキュメントベースのデータ抽出に特化して設計されています。
- セキュリティおよび認証 - JSON Web Tokenの管理や、SHA-256ハッシュ生成といった暗号化操作のためのユーティリティ。
- アーカイブ管理 - ストリームベースのインターフェースを通じたTARおよびZIPアーカイブの作成、読み込み、内容確認のサポート。
