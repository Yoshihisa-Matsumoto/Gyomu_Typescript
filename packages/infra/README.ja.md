# Gyomu Infra

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomuエコシステムのコアインフラストラクチャ層として機能し、Effectベースのアプリケーション向けに設計された堅牢なサービス群を提供します。ファイル管理、データベース接続、ネットワーク通信、データ変換といった低レベルのシステムインタラクションを抽象化し、一貫性のある型安全な実行環境を提供します。

アプリケーションロジックをプラットフォーム固有の実装や外部ライブラリから切り離すことで、複雑な業務オペレーションのための安定したインターフェースを確立します。また、一貫したエラーハンドリングと信頼性の高い依存性注入パターンを強制し、開発者がコアロジックに集中できるようにすると同時に、エコシステム全体でスケーラブルかつ予測可能なアーキテクチャ基盤を維持します。

## アーキテクチャ

@gyomu/infraパッケージは、モジュラーアーキテクチャを採用し、ビジネスロジックと実行環境のインフラストラクチャを分離します。このパッケージは、実行環境に基づく設定とサービス層の定義を一元管理するハブを提供し、アプリケーション全体で一貫した依存性注入を実現します。低レベルなシステム操作を共通のラッパーで抽象化することで、標準化されたエラーハンドリングと予測可能な動作を保証します。

このパッケージは、特定のインフラストラクチャの懸念を処理する専門的なドメインに整理されています。ファイルシステムとアーカイブモジュールはローカルI/Oとメタデータを管理し、データベース層は接続のライフサイクルとリポジトリパターンを抽象化します。ネットワーク通信とデータのシリアライズは専用のモジュールが担当し、未加工のストリームをJSON、XML、CSVなどの構造化フォーマットへ変換します。これらのコンポーネントは設定プロバイダーとユーティリティ層を共有して連携することで、リモートのWebソース、ローカルストレージ、データベースサービス間でのスムーズなデータフローを可能にします。このモジュラー構造により、基盤となる実行環境に依存しない、堅牢でスケーラブルなアプリケーションを構築できます。

## インストール

pnpmを使用してインストールします。

```bash
pnpm add @gyomu/infra
```

## 依存関係

本パッケージはNode.jsを必要とし、ESM専用環境で動作するように設計されています。コアとなるランタイムにはEffect 4.xを採用し、共有の型やスキーマ定義には`@gyomu/schema`を活用しています。本ライブラリはモジュール化された設計を採用しており、SSH、FTP、Zipユーティリティ用に個別のエクスポートパスを備えています。これらの依存関係は明示的にインポートされた場合にのみ読み込まれるため、それらの機能が実装に不要な場合、ランタイムを軽量に保つことができます。

## 開発

Gyomuエコシステムの共通インフラストラクチャ基盤は、アプリケーションロジックをランタイムや外部リソースの直接的な依存から切り離すことを核心としています。すべての副作用はEffectベースのサービスとして抽象化され、型安全なエラー処理と共に提供されます。開発者は特定プラットフォームや外部ライブラリへの直接的な参照を避け、定義されたサービスインターフェースを通じてインフラ操作を行うことで、業務知識を汚染することなく安定した実行環境を維持することが求められます。本パッケージへの貢献にあたっては、データ整合性の保証とシステムの拡張性を最優先してください。データ変換の境界では常にスキーマ検証を実施し、大量データ処理においてはストリームベースのアプローチを採用することで、リソース効率と安全性を両立させる必要があります。また、データベース操作はRepositoryパターンに従い、エラーは診断可能な共通モデルとして適切に分類・管理してください。これらの指針を守ることで、特定のアプリケーションに依存しない再利用性の高い基盤として、Gyomuエコシステム全体の一貫性を担保します。

## Public API

- ファイルシステムオーケストレーション - ファイルやディレクトリの管理、メタデータの取得、検索、ストリームベースのI/Oなど、包括的な操作群。
- データベース抽象化 - SQLデータベースとのやり取りのための統合サービス。接続管理、Repositoryパターン、カスタムクエリ実行機能を備えています。
- ネットワークおよびWeb統合 - HTTPリクエスト、Webスクレイピング、ドキュメント解析、リモートデータストリーム処理のためのツール。
- データシリアライズおよびパース - 構造化データモデルとCSV、XML、YAML、JSONといった一般的な形式間の双方向変換機能。
- セキュリティおよび認証 - JWTベースのアイデンティティ管理とSHA-256ハッシュ化などの暗号化操作のためのユーティリティ層。
- アーカイブ処理 - ストリームパイプライン内でZIPやTARアーカイブの確認、読み取り、内容抽出をサポート。
